# Step 48 — 검토한 ZIP과 기능 기준 확정

Phase 26.2 · 2026-11-19 12:12:40–12:16:46 +0900 · 예상 45–90분

## 수행

Step 47에서 보정한 애드온과 수동 설치 안내를 새 경로에서 세 ZIP으로 빌드했다. 최신 기능 지도와 마스터 플랜에 설치본의 세로 경험치 막대, 기본·대체 유닛 프레임과 한 접속 확인의 연결을 기록했다. [기능 트리](../../Collection/data/feature-map.md) · [게임 확인표](../../References/codex-verify/one-session-review.md)

| 변형 | 애드온 폴더 | 파일 | Lua 5.1 | 역할 |
|---|---:|---:|---:|---|
| PitBull4 | 35 | 2,279 | 1,344 | 기본 단독판 |
| Forever Unit Frames | 37 | 2,215 | 1,290 | 승인 해시를 고르는 대체 단독판 |
| 한 접속 비교판 | 38 | 2,524 | 1,476 | 한 캐릭터로 교대 시험 |

전체 SHA-256과 바이트, 폴더명은 [검토 기록](audit-installer/reviewed-packages.json)에 있다. 아무 변형을 지정하지 않은 기본 명령과 명시한 PitBull4 ZIP의 해시는 같다. 두 단독판만 [설치기 카탈로그](../../Collection/Installer/ReleaseCatalog.json)에 넣었다. 버전 0.1.0과 Interface 16001을 기록했다.

## 근거·판단

- 이전 후보와 새 후보의 내부 SHA-256 목록에서 채팅 Lua 두 파일, 수동 가이드, 해시 목록만 달라졌음을 확인했다. FUF 시험에 쓰인 항목의 해시는 그대로다. 최종 압축에서 Lua와 필수 의존성 각 실패 0건, 채팅 28건을 확인했다. [ZIP 원출력](../../_local_only/phase26-work-r151-20261119/step47-candidate-02/verify-archives.log) · [채팅 원출력](../../_local_only/phase26-work-r151-20261119/step47-candidate-02/packaged-chat.log)
- 기존 로컬 소스와 vendor 원본을 이용해 빌드했다. 결과는 이 작업 트리의 실제 ZIP을 고정한 기록이며 이전부터 별도로 수정 중인 파일을 일괄 커밋하지 않았다.
- 대체판과 비교판에서 FUF를 별도 프로필로 확인한다. 화면 배율, 전투 보호, 4K 퀘스트 글자, 실제 유닛 프레임 선택, 파티·공격대 확인은 게임 관측에 둔다. 추가 해상도 이름과 4K 단독판은 기존 결정 대기에 남겼다.

| 영향 위치 | 처리 |
|---|---|
| 현행 기능 트리·마스터·한 접속 표 | 화면 배치 근거와 오프라인에서 직접 적용한 좌표를 대조한다 |
| 배포 ZIP→설치기 | 실제 매니페스트의 이름·판·전체 해시·내용 수를 카탈로그에 전달한다 |
| SHA-256 기록·이전 원천·빌더 | 읽기 및 비교. 표의 수치와 내부 포맷은 유지했다 |

## 게이트

독립 검수에서 SHA-256 세 개와 바이트·기본 ZIP·포함 항목을 다시 대조했다. 열 관점 검토에서 나온 중간 한 건은 게임 확인표의 최종 기준 링크였다. 같은 작업자가 Step 48 결과와 정확한 파일명·경로로 연결했고, 같은 검수자가 대상 두 파일의 경로와 링크를 확인했다. 최종 중대·중간·경미 0건이다. 검수 사용량 미관측. [보정 기록](audit-installer/step47-work-log.md)
