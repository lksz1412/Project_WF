# Step 76 · 한 접속 확인표와 설치기 인계

| 연결 | 변경과 확인 |
|---|---|
| 한 접속 확인표와 상세 확인표 | 사용자 요청 5-1~5-6을 두 문서에 기록. 0.1.4의 기존 관측과 다음 판을 구분 |
| Core 저장·복원 명령 | Commands, Profiles, Presets의 실행 경로와 대조. 저장과 복원 대기에는 각각 go가 필요하며 취소 후에는 다시 불러오지 않는 조건을 적음 |
| 설치기 입력 | 현행 카탈로그, 설치기 계약, ApprovedPackage 읽기 경로 확인. 실제 0.1.5 ZIP의 해시, 폴더 목록, 바이트 수를 넣을 명세로 정리 |
| Claude 인계 | 작업용 브랜치, 사용자 원문, 배치와 한 접속 확인 링크. 두 제품 공통 시험의 기준 실패를 재현해 기록 |
| 보호 파일 | Collection과 Claude 경로, 0.1.4 배포 파일에 쓰기 없이 설계·검증 자료만 추가 |
