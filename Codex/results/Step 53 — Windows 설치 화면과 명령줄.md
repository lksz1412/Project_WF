# Step 53 — Windows 설치 화면과 명령줄

Phase 27.3 · 2026-11-19 13:03–13:44 +0900 · 예상 90–150분

Windows Forms 화면과 명령줄이 같은 파일 엔진으로 승인 ZIP을 미리보고 설치·검증·복원·제거한다. 설치 화면은 게임 폴더, 기본 PitBull4 또는 승인 FUF ZIP과 작업을 선택하고 변경·보존·충돌 목록을 보여 준다. 입력이 바뀌면 다시 확인하며 작업이 끝나기 전에는 중복 실행을 막는다. [사용 안내](../../Collection/Installer/사용안내.md) · [구현 기록](audit-installer/step53-ui-work-log.md)

## 실행과 검수

- 실제 Windows Forms 메시지 루프에서 기본 흐름 5개를 서로 다른 두 경로에서 확인했다. 명시 인수→설치→같은 입력을 다시 미리보는 호출은 `no-change`였고 실행은 비활성이었다. 공유 결과는 경로를 제외하고 미확인과 정상 미설치를 구분했다. [실제 화면 코드 시험](../../_local_only/phase26-work-r151-20261119/step53-reviewfix-vkngg5dm/ui-actual-install.json)
- 별도 Windows 창의 접근성 트리에서 설치 ZIP, 변경 34개·보존 1개·충돌 1개, 해당 폴더의 인수 선택과 적용 비활성 상태를 보았다. 초기 행 표시의 예외를 보정했다. 첫 화면 도구의 실행 승인은 시간 초과였고 로컬에서 실행한 창으로 확인했다. 보정 확인 때 별도 이전 시험 프로그램의 오류 창이 화면을 일부 가렸다.
- 최종 WinExe의 리디렉션 표준 출력과 종료 코드 0·2, 도움말 성공을 확인했다. 빌드 경고·오류 0건. [작업 기록과 실행 위치](audit-installer/step53-ui-work-log.md)
- 독립 검수에서 나온 중간 2건과 실제 결과 표 그리기 문제를 같은 작업자가 보정했다. 재확인에서 소스·시험 해시, 실제 인수 이후 무변경, 표의 편집 보호와 공유 결과를 대조했다. 최종 중대·중간·경미 0건, 사용량 미관측.
