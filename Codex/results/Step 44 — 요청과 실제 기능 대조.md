## 근거·판단

- 공통 배치·테마·복원은 Core, 고유 옵션은 각 애드온이 관리한다. CR112에 따라 기본 채팅과 자체 창·외관을 채택했다. 상태 알림·쿨다운은 게임 기본 Cooldown Manager를 사용하고 Hekili는 추천을 맡긴다. 이전 Prat 및 보완 전투 모듈 제안은 현행 설치의 근거로 쓰지 않는다.
- PitBull4는 비교 전 시험 기본판이다. FUF 외관 조각은 제안으로 남아 있고 현재 기본값 애드온은 공격대 프레임 제어만 제공한다. 최종 기본판은 같은 접속의 비교 뒤 결정한다.
- FHD·QHD·UHD 실물 세 프리셋을 확인했다. 과거 사용자 원문에는 세 이름과 「4종」이 함께 있으므로 제4판과 4K 단독 여부는 열린 상태다. 4K 퀘스트 가독성, 기본 쿨다운 관리자의 실제 편집 모드 위치, 가로 경험치 제안은 현재 코드에서 검증한 좌표와 구분했다.
- 기존 8개 오프라인 시험 묶음은 모두 통과했다. 기존 ZIP을 읽은 별도 Lua 5.1 시험에서 메시지 추가 API 부재 시 31개 구독 원본 제거, 두 번째 창 실패 시 12개 그룹의 부분 이동, UHD 생성 뒤 QHD에서 오른쪽 창 x=2910 유지와 쓰기 0건을 재현했다. 실제 게임 동작은 Step 41에서 관측한다. 채팅 시험 기록 (로컬 전용) · 두 번째 창 실패 (로컬 전용)
