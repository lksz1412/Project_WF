## Claude 코드에서 적용할 내용

- 파티·공격대는 Grid2를 쓰고 PitBull4의 파티·파티 대상·파티 소환수 표시는 끈다. FUF 비교판에서도 파티 표시가 하나인지 대조한다. 해제 테두리, 사거리 흐림, 들어오는 치유 기본값은 신규 프로필에 적용한다. 기존 사용자 프로필을 사용하는 경우의 결과를 따로 확인한다.
- 적 소환수는 `targetpet`의 실제 표시 여부에 따른다. 기존 적군 색과 이름 왼쪽 정렬을 유지한다. 대상의 대상, 대상의 대상의 대상, 주시 대상의 대상은 원래 설정과 비교한다.
- PitBull4 토템 표시는 주술사에게만 켠다. 모듈에 다른 직업 분기도 있으므로 모듈의 전역 켜짐만으로 직업 조건을 판정하지 않는다. 플레이어 왼쪽 위, 가로 네 칸과 남은 시간은 [배치 기준](../../References/codex-appearance/25-codex-handoff/positions.json)을 적용한다. Dominos의 기존 토템 기술 버튼은 별도로 확인한다.
- SexyMap은 원래 쓰던 캐릭터의 기존 프로필 위치와 크기가 유지되는지 본다. 미니맵 시계와 상태띠 시계 확인은 기존 화면 확인표를 따른다.
- 0.1.4는 GitHub 시험판이다. 0.1.5 사용자 ZIP에는 게임이 읽는 애드온 파일을 담고, 제3자 원본·diff·진단·시험·예비 그림은 개발 브랜치에 둔다.

## 검토 의견과 아직 확인할 부분

- Aurora는 기본판 미포함을 권장한다. 이름표·쿨다운 관리자 스킨이 겹치고, 불러올 때마다 `questTextContrast`를 4로 쓴다. [앞선 검토](../../Claude/results/PHASE_15_aurora_RESULT.md)
- 승인된 크기에서는 테마 13종을 낱개 이미지로 나눈 다음 합쳐도 픽셀 차이가 0이다. 창 크기를 개별로 바꿀 때는 모서리와 연결부를 유지하고, 셋째 채팅창의 문양을 바탕·테두리와 분리해 그리는 방법을 추가 검증한다. 낱개 운용과 두 장의 합성판은 실제 게임에서 프레임 시간도 비교한다.
- 적응형 배치는 기존 화면 높이 선택에 실제 폭과 슬롯 조건을 더한다. 물리 슬롯 → 줄·간격 → 하단에서부터 쌓기 규칙과 세 해상도 수치를 외관 자료에 적었다.
- 기본 프레임(PitBull4/FUF)은 게임 비교 뒤 결정한다. Hekili와 선택 애드온 안내는 후속 논의에 둔다.

## Claude 합친 뒤의 공통 확인

`Collection/tests/core/run.py`를 전체 실행하고 `Collection/tools/genregistry.py --check`를 함께 확인한다. Codex가 기준 `477eb06`에서 확인한 값은 Core 107/108건이다. 실패 1건과 등록표 조회 실패는 Details가 빌드 manifest의 collection 항목에 없다는 같은 오류였다. 이번 인계에는 `Collection/` 및 `Claude/` 변경이 없다. 외관은 오프라인 목업에서 확인했고, 실제 게임 조건은 한 접속 확인표에 있다.
