## 한 접속에서 기록할 것

1. [기존 한 접속 확인표](../../References/codex-verify/one-session-review.md)의 해상도·배율과 활성 애드온을 먼저 기록한다. 유닛 프레임 두 판의 환경은 같은 캐릭터·장소·그래픽 설정·보이는 장비와 창으로 맞춘다.
2. PitBull4로 시작한다. 대상의 대상이 그대로 있는 상태, 대상이 바뀌는 상태, 같은 대상에서 체력·자원만 바뀌는 상태를 차례로 본다. 파티원으로 연결되는 대상과 주변의 독립 대상은 따로 적는다. 같은 전투에서 제한 상태가 확인되는 경우 오류·수치·오라·프레임 시간을 별도 기록한다.
3. 전투 밖에서 기존 확인표대로 FUF로 바꿔 같은 구간을 반복한다. 체력·자원, 켠 오라와 시전바, 치유 예측과 거리 표시 수를 각 판에서 맞춘다. 맞출 수 없는 케이스는 기능 차이를 적고 시간 수치의 비교에서는 분리한다.
4. 두 판에서 정상 표시와 보호 프레임 오류가 먼저다. 같은 구간의 프레임 시간과 느린 구간은 확보한 샘플로 판단한다. 값이 한 번만 나타나거나 그래픽 차이가 큰 경우 확정 근거로 쓰지 않는다.
5. 퀘스트 글자 크기는 기존 4K 확인을 그대로 사용한다. 후보 애드온을 더 켜는 시험은 실제 필요한 기능이나 대상 콘텐츠가 확인된 경우 진행한다.
