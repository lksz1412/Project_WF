# Step 64 — FUF 비교 배치 반복 조회 줄이기

2026-11-19 · Phase 29.3

## 수행

비교 배치를 실행할 때 처음 한 번만 진단 상태에서 캐릭터 키를 읽는다. 각 명령 전에 전투 상태, 현재 프로필 이름·객체, 저장 변수 객체를 확인한다. 같은 이름의 비교 프로필 객체라도 도중에 교체되면 다음 쓰기를 중지한다. 명령 순서와 저장 위치는 동봉 FUF의 공개 명령을 따른다.

## 근거와 판단

| 위치 | 영향 | 확인 |
|---|---|---|
| `NativeLayout.lua`의 활성 프로필 읽기와 명령 루프 | 함께 수정 | 조회는 한 번, 변경 직전의 전투·대상 확인은 모든 명령에 적용 |
| `FUFDefaults.lua`의 진단 상태와 `LayoutPresets.lua` | 확인만 | 키 생성과 116개 레이아웃 명령의 기존 형식·개수 유지 |
| 동봉 FUF `Core/Config.lua`, `Core/Commands.lua` | 확인만 | 개별 공개 명령과 설정 기록의 기존 처리 유지 |
| FUF 회귀 시험 | 함께 수정 | 실물 FUF로 비교 배치의 정상 쓰기와 같은 이름 객체 변경, 지정 상태 반환, 사용자 기존 프로필 보호를 확인 |
| 기본판과 비교판 | 확인만 | FUF 변경 파일은 FUF와 한 접속 비교 ZIP에만 해당한다. 기본판의 로드 목록에 없다. |

승인 세부계획을 다시 읽고 FUF 명령과 설정 원문을 대조했다. [구현자 확인 범위와 시험 출력](../../_local_only/perf-package-0.1.2/step64-work.md)

## 변경 파일

`Collection/AddOns/DevilForever_FUFDefaults/NativeLayout.lua`, `Collection/tests/fufdefaults/run.py`.

## 확인

`python -B -I Collection/tests/fufdefaults/run.py` 종료 0. 22개 시험 통과. 세 프리셋과 두 배율에서 696개 설정값을 동봉 설정 모듈로 읽어 대조했다. 이전 117회 진단 조회에 비해 1회로 줄였으며 정상 시 발송 116개를 유지했다. 같은 이름 프로필 객체 교체 때 첫 한 명령 뒤 중지했다. 실제 게임에서 FUF가 리스너를 그리는 비용은 미측정이다.
