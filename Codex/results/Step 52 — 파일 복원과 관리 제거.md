# Step 52 — 파일 복원과 관리 제거

Phase 27.2 · 2026-11-19 12:44–13:03 +0900 · 예상 90–150분

## 수행

같은 파일 엔진에 검증, 직전 설치·제거 복원, 관리 폴더 제거와 중단 상태의 복원 명령을 연결했다. 판이 바뀌는 설치, 원래 폴더 인수와 복구, 중단 뒤 재실행은 기존 게임 대역과 분리한 새 경로에서 검증했다. [설치 계약](../../Collection/Installer/Contract.md) · [구현·영향 기록](audit-installer/step52-recovery-work-log.md)

## 근거·판단

| 확인한 흐름 | 실제 결과 |
|---|---|
| PitBull4 → FUF → PitBull4 → 복원 | 각 단독판 전용 폴더, 실제 설치 파일 해시, 복원한 FUF와 기존 파일을 대조했다. 반복 미리보기는 `no-change`였고 파일이나 기록 차이가 없었다 |
| 기존 같은 이름의 폴더 인수 → 복원 | 검증한 원본 백업을 새 준비본으로 복제하고 이전 파일을 되돌렸다. 사용자 원본 파일과 원래 백업을 확인했다 |
| 관리 제거 → 제거 이전 복원 | 사용자 파일이 들어간 폴더는 제거 대상에서 제외했다. 나머지 관리 폴더만 이동했고 제거 이전 파일 목록과 SHA-256까지 복원했다 |
| 작업 상태의 중단 처리 | 파일과 활성 기록이 이미 확정된 경우 완료 기록을 마감한다. 미완 복원은 원래 복원 실행 ID의 목표까지 이어간다 |
| 설치기 실제 강제 종료 | 원래 사용자 파일의 백업 이동을 확인한 뒤 시험 프로세스만 종료했다. 저널은 `applying`과 완료 이동 4건을 기록하고 있었다. 재실행한 공개 명령으로 원래 게임 대역의 파일 지문을 복원했으며 백업이 남았다 |
