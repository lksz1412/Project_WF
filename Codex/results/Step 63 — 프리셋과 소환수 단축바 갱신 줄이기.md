# Step 63 — 프리셋과 소환수 단축바 갱신 줄이기

2026-11-19 · Phase 29.3 · 실행 승인 뒤 작업

## 수행

프리셋 복원 동안 필드별 저장과 기존 변경 알림을 즉시 전달한다. 자체 외관·Dominos 스킨·이름표 스킨·기본 채팅 스킨·상태 띠는 같은 복원에서 그리기 요청을 모아 마지막에 각 한 번 처리한다. 일반 편집과 테마 변경의 즉시 적용은 유지한다.

Dominos 소환수 버튼의 부착·해제는 같은 시점에 모아 현재 소환수 바만 갱신한다. 분리한 버튼의 테두리를 숨기며, 전투 중에는 보류하고 전체 갱신이 끝낸 예약은 다시 처리하지 않는다.

## 근거와 판단

## 변경 파일

Core `Edit.lua`, `Presets.lua`, `API.lua`, 자체 외관 `Appearance.lua`, Dominos·이름표·기본 채팅·상태 띠 스킨과 [회귀 시험](../../Collection/tests/performance/run.py).

## 확인

`python -B -I Collection/tests/performance/run.py --dominos-zip <0.1.1 기본 ZIP>` 종료 0. UHD→QHD, QHD→FHD, FHD→UHD 외관 갱신 39회에서 1회, 합성 질감 호출 78회에서 2회. 필드 알림 39개 유지. 편집값을 지울 때 필드 알림 40개 유지. 다섯 스킨 각각 1회. Dominos 10개 버튼 재구성 시 다른 바 글꼴 20회에서 0회, 소환수 100회에서 10회, 예약 1회. 게임 안 시간과 FPS는 미측정이다.
