# Step 46 — 기능별 반증 시험

Phase 26.2 · 2026-11-19 11:24:48–11:39:42 +0900 · 예상 120–210분

## 수행

동일한 세 기준 ZIP과 현행 소스로 공통 배치·복원, 대화, 하단 조작, 유닛·전투, 그룹·기록, 성장·퀘스트와 문서의 연결을 반증했다. 기존 정상 호출은 Step 44의 여덟 시험 기록을 사용하고, 기존 시험이 다루지 않은 조건은 ZIP의 실제 Lua를 시험 대역에서 호출했다. [기능별 실행·정독 기록](audit-installer/step46-work-log.md) · [발견과 시험 조건](audit-installer/step46-findings.json)

| 판정 | 실제 근거 | 반영 단계 |
|---|---|---|

| 중간 1 | 현행 기능 지도가 연결한 지원표에 보완 전투 모듈과 쿨다운 결정 대기가 남음. 현재 설치에는 해당 모듈이 없고 기본 Cooldown Manager가 담당 | Step 47–48 |
| 수용 범위 | 경험치 가로 사각형은 공간 대안이다. 설치본의 세로 상태와 실제 사용 수치를 기준으로 기록하고 가로 대안의 위치와 표현을 별도로 밝힘 | Step 48 |

13개 테마와 세 프리셋에서 실제 ZIP의 외관 Lua·텍스처를 호출했다. 데빌은 문양 없이 표시됐고 나머지는 오른쪽 채팅창 내의 70%×70% 영역과 16% 불투명도를 사용했다. PitBull 대상 위에 보이는 테마 픽셀은 없었다. SexyMap의 새 프로필은 미니맵 시계를 숨기며 기존 사용자가 저장한 시계 설정은 그대로 쓰는 경로를 확인했다. [추가 실행 근거](../../_local_only/phase26-work-r151-20261119/step46-root/root-audit-notes.md)

자료를 판단한 범위는 작업 기록의 정독 표와 자체 게이트에 있다. 프로젝트 담당자는 작업 기록 1–257행, 발견 JSON 1–496행, 현행 세부계획 1–36행, 채팅 설정 1–265행·배치 1–54행, FUF `Core/UnitProfiles.lua` 1–185행·`Core/Storage.lua` 1–268행·`Core/Commands.lua` 1–143행, 외관 합성 1–134행, ZIP과 관련 실행 기록을 대조했다. 실제 게임 세션은 Step 41의 별도 근거가 필요하다.

## 변경·생성 파일

기능 감사 자료 두 파일, 이 이력, 실행 대장과 Phase 26.2 진행 표시를 기록했다. Step 47 대상으로 확인한 기존 파일 11개의 해시가 같은 사본을 격리 경로에 확보했다.

## 게이트

기능 10개 행, 근거 18개 원문 인용, 실제 실행·사용자 보존·게임 미검증 구분을 검증했다. 독립 검수의 중간과 경미 각 1개는 경험치 대안의 범위·인용 링크 문제였다. 같은 A 수정과 같은 B 재검 후 감사 자료의 미해결 결함은 0건이다. 애드온·현행 문서의 중대 1·중간 4는 Step 47–48에서 수정한다. 사용량 원시값은 제공되지 않았다.

## 다음
