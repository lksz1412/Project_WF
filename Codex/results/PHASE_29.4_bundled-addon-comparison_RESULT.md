# Phase 29.4 동봉 애드온 기능별 오프라인 비교

## Summary

11개 기능의 동봉 애드온과 비교 후보를 순서대로 검토했다. SexyMap의 숨은 좌표 조회와 Experience Forever의 퀘스트 목록 반복 조회는 실제 동봉 Lua에서 재현하고 파일 수준 변경안으로 만들었다. PitBull4와 FUF는 파생 대상의 상태에 따라 전체 갱신 횟수의 우열이 바뀌었다.

## Step Range

Step 66–69.

## Inputs

[기능별 비교 순서](../plans/2026-11-19-devil-forever-addon-adoption-plan.md#동봉-애드온과-같은-기능-후보의-비교-순서), 0.1.2 동봉 파일, 보관 중인 비교 후보와 정확한 배포판의 제작자 기록.

## Files Created

[유닛 프레임](Step%2066%20%E2%80%94%20유닛%20프레임%20동작%20비교.md), [행동 추천과 전투 미터기](Step%2067%20%E2%80%94%20행동%20추천과%20전투%20미터기.md), [기능별 후보](Step%2068%20%E2%80%94%20기능별%20후보와%20반복%20비용.md), [실제 게임 비교와 수정안](Step%2069%20%E2%80%94%20실제%20게임에서%20확인할%20성능%20비교.md).

## Files Updated

마스터 플랜과 실행 대장에 29.4와 비교 결과를 연결했다.

## Read Coverage

시작의 마스터 플랜 1–159행, 29.3 결과 1–49행, 기존 유닛 비교 1–68행, 선택 설치 Step 61 전문, 한 접속 확인표 전문을 대조했다. 소스와 ZIP의 파일·행 범위는 Step 66의 작업 기록, Step 67의 확인 범위, Step 68의 근거에 적었다.

## Execution Evidence

유닛 프레임 16조건, Hekili 스케줄러 5조건, Details의 화면 타이머 3조건을 Lua에서 실행했다. Bartender4의 소환수 키 재지정, SexyMap 좌표 끄기·재시작, Experience Forever 목록 갱신을 따로 검증했다. 두 변경안은 새 시험 폴더에 적용하여 실행 대역에서 검증한 코드의 해시와 일치했다.

## Validation

실행 대역과 결과 기록, 패키지 해시, 변경안 적용을 대조했다. 검수 결과와 실제 게임 비교의 수용 조건은 [Step 69](Step%2069%20%E2%80%94%20실제%20게임에서%20확인할%20성능%20비교.md)에 남긴다.

## Non-Changes

0.1.2 ZIP 세 개는 앞서 기록한 해시와 일치한다. Lua 시험은 로컬 시험 폴더에서 실행했다.

## Open Issues

사용 환경에서 두 유닛 프레임의 동등한 화면 구성, 평시·전투 프레임 시간과 표시 정확성은 미측정이다. 일부 선택용 애드온은 제작자 자료나 기존 코드 확인까지만 진행했다. 신규 던전의 보스별 실제 경보, 거래 기능의 응답, 지도와 전문기술 창의 성능은 미검증이다.

## Decision Queue

기본 PitBull4와 FUF 비교판을 유지한다. 기존 역할을 더 잘 수행한다는 근거가 있는 경우에만 교체한다. 파일 수준까지 재현한 두 변경안을 앞에 두고, FUF의 숨은 프레임 갱신과 Details의 표시 간격은 각각 비교 조건에 따라 다룬다.
