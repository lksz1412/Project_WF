- 설명 -



현재의 애드온은 데빌님이 복귀하기전 임시적으로 올리는 애드온입니다.



문제가 있을 시에는 삭제를 하겠습니다.



- 환경 -



애드온 작업을 위하여 노트북을 하드포멧 후에 고스트 및 comeback7.0을 설치 하였습니다.

해상도 테스트를 위하여 1928 X 1080 모니터를 사용하였습니다.

백신 프로그램은 avg로 바이러스 테스트 후에 유저분들이 안전하게 사용할 수 있도록 노력하였습니다.



애드온의 파일 용량은 8.3MB 입니다.





- 설치 방법 -



DevilUI 4.3.0.f를 설치 하고 개인 설정을 한 후에 Interface / addons에서 addons를 삭제 하기를 바랍니다.

addons를 삭제하고 애드온 데이터를 받아서 Interface 폴더 안에 넣기를 바랍니다.





- 애드온 설명 -



BlueItem 계열이 일부 오류가 있어 일부 정상 작동 하지 않습니다.

BlueItem 계열을 비활성화나 무시로 당분간 사용하기를 바랍니다.



FairComboPoints는 콤보 애드온으로 초기값으로 지정 되어 있어 본인에 맞게 설정 하시기 바랍니다.!!

FairComboPoints를 사용하지 않을 경우에는 삭제하거나 비활성화 하기 바랍니다.



KgPanels에서 간혹 녹색 바탕 화면이 나올 경우가 있습니다.

KgPanels 설정창을 오픈 후에 해당 녹색화면에서 투명화 0를 하면 녹색 화면이 없어집니다.



InvenRaidFrames3 팬 버전이 올라와 업데이트 하며, 안정화 될때까지 Grid, Sraid, Vuhdo를 권장합니다.



Recount가 일부 특성이 안잡히는 경우가 있어, skda를 사용하셔도 좋습니다.
