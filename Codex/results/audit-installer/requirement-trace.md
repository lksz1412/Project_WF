# 요청과 현행 기능 대응

2026-11-19T11:08:57+09:00 · Phase 26.1 · Step 44

요청 대장 24개에 남은 R1–R110·CR111–CR149·R150–R151 식별자를 실제 기능 담당과 연결했다. R103은 당시 Claude 질문 기록이며 사용자 발화에 연결된 대장 행 150개와 구분한다. 대장 요지와 대화 원문은 구분한다. 이번 문서 대조와 master가 별도 실행한 기존 ZIP의 Lua5.1 반증을 각 출처로 적고 실제 게임 관측은 미검증으로 둔다.

요청 원행을 주 출처로 두고 뒤 Phase의 같은 번호는 이월·처리 상태로 연결했다. 범위행 두 개는 개별 요청을 대신하지 않는다. R13의 매크로·설정 범위 차이를 별도 열린 항목으로 남겼다.

## 확인 수준

현행 경로는 요청별 담당·문건·시험을 직접 가리킨다. 게임 기본 CDM과 countdownForCooldowns, 제외한 기본 기능은 설치 애드온이 있는 것처럼 표기하지 않았다. 이번 A가 전문을 읽은 실제 Lua는 작업 기록의 범위를 따르며 그 밖의 호출 검증은 후속 Step46에서 한다. master의 채팅 Lua5.1 반증은 T4에 연결했고 실제 게임 결과로 세지 않는다.

모든 출처·개별 행·범위행·중복 행과 ZIP 변형은 [기계용 대응표](requirement-trace.json)에 있다. 실제 읽은 파일·행 범위와 기계 검사 결과는 [작업 기록](step44-work-log.md)에 남긴다.
