## 독립 검수 보정 결과

복원 완료의 활성 기록은 이전의 판·파일·보존 payload에 새 복원의 `lastRunId`와 `lastAction=rollback`을 붙여 원자 교체한다. 완료 동작·ID와 payload를 함께 검사하므로 교체 직후 종료도 같은 복원 실행으로 식별한다. 미완 복원은 `revertsRunId`로 원래 실행과 연결해 우선 선택한다. 복원 완료 뒤 파일이 같으면 다음 복원은 `no-change`이고 새 적용·제거만 복원 대상을 다시 만든다. A→B→복원→복원의 대상·관리 지문 일치를 수용표에 넣었다.

파일 생성 없는 OS named mutex를 사용하고, 기존 기록·현재 파일·확인값·반대판 충돌을 모두 대조한 뒤에 실제 쓰기를 시작한다. blocked·오래된 확인값·no-change는 게임 대상과 관리 영역의 파일 목록·해시 차이 0을 요구한다. 관리 영역이 없던 경로도 그대로 없는 상태로 끝낸다.
