## 경험치 막대와 단축바 그림 확인

- 경험치 막대의 적용 기준은 채팅창 아래 화면 최하단이다. 이전 외관 안은 긴 윗줄 바로 아래의 검은 띠에 세 막대를 놓는 안이었다. 시험 설치본의 세 해상도 설정은 Experience Forever의 글꼴·질감·색만 제공하고 위치나 높이를 제공하지 않는다. 채팅창 바로 아래에 남겨 둔 하단 띠에서 경험치 막대의 자리를 잡고, 상태 표시 및 채팅 하단 테두리와 겹침을 확인해야 한다.
- 소환수 단축바가 없으면 버튼과 네모 틀 전체가 보여서는 안 된다. 설치에 쓴 `Themes/devil/Composition/uhd_top.tga`를 열어 확인했다. 긴 주 단축바 위의 소환수 칸 아랫테두리가 같은 그림에 남아 있다. 제작 도구는 큰 그림을 단축바 쪽과 채팅창 쪽 두 장으로 나누며, 단축바 쪽 그림에 소환수 구역도 포함했다. 게임에서는 Dominos가 실제 소환수 버튼의 표시를 제어하지만 합성 그림은 독립적으로 표시된다. 설치 자료 13종·3해상도에 단축바 그림 39장과 소환수 버튼 테두리 13장이 있으며, 소환수 없는 상태용 긴 단축바 그림은 없다. 긴 줄 바탕에서 소환수 자리를 걷어 내고, 실제 소환수 스킬바가 표시될 때만 해당 장식을 붙여야 한다. 개별 파츠로 표시되는 경우에도 같은 조건을 확인한다.
- 게임 화면 배율을 100%로 바꾸면 위치는 가까워지지만, 단축바 프리셋이 테마 바깥 치수 전체를 버튼에 배정한다. 36칸과 2픽셀 간격의 가로 길이는 FHD 1798픽셀, QHD 2086픽셀, UHD 2950픽셀로 각각 긴 틀의 바깥 너비와 같다. 높이도 버튼과 틀이 각각 48·56·80픽셀로 일치한다. 긴 틀의 안쪽 여백을 빼지 않아 단축바가 틀의 장식을 가릴 수 있다. 테두리 안쪽의 실제 빈 공간을 기준으로 버튼 크기와 시작점을 맞추고 `1~0` 및 `F1~F12`가 지정된 주 줄에 있어야 한다.

근거는 설치에 사용한 `Composition.lua`, `Appearance.lua`, `DevilForever_Skin_Dominos/Skin.lua`, 세 해상도의 설치용 프리셋, `uhd_top.tga`와 `uhd_deck.tga`, 그리고 `References/codex-appearance/24/geometry-checks.json`의 좌표다. 이 확인에서는 설치 파일과 게임 설정을 변경하지 않았다.

## 2026-11-24 일렬 비교판 · 스윙 조사

포에버는 `PLAYER_SWING`에서 다음 평타까지의 시간과 주무기, 보조무기, 원거리 구분을 보낸다. 번들 Quartz의 포에버 모듈은 주무기와 원거리를 같은 바에 표시하고 보조무기는 건너뛴다. 첫 발이 나간 뒤 다음 주기를 표시하며, 예정 주기가 끝난 뒤 새 발사가 없으면 숨는다. 사냥꾼은 발사 사이에 이동할 수 있고 자동 사격이 나가는 마지막 구간에서는 멈춰야 한다. 늦게 멈추면 다음 발사가 늦어질 수 있다. ## V1과 V2 비교판 자동 확인

V2는 내 소환수, 플레이어, 주시 대상, 선택 대상, 선택 대상의 소환수를 하단에 왼쪽부터 둔다. 큰 두 창의 크기와 작은 정보 창, 조건에 따른 표시를 유지했다. 세 유닛의 시전 막대는 같은 높이에 있고 플레이어 시전에만 화면 중앙 아래 막대를 하나 더 쓴다. 중앙 시전 아래 스윙 한 줄은 마지막 원거리 또는 주무기 근접 평타의 주기로 바뀐다. 게이지 값은 포에버가 보낸 시간으로 기존 콜백에서 직접 갱신한다.

| 해상도 | 큰 창의 연속 범위 | 유닛별 시전 막대 위쪽 | 중앙 시전 막대 위쪽 |
|---|---:|---:|---:|
| 1920×1080 | 위 593px, 아래 665px | 710px | 548px |
| 2560×1440 | 위 863px, 아래 959px | 1014px | 765px |
| 3840×2160 | 위 1370px, 아래 1514px | 1588px | 1180px |

4K에서 `/dfp preset uhd-v2` 또는 `/dfp preset uhd-v1`을 예약한 뒤 `/dfp go`로 바꾼다. FHD는 `fhd`, QHD는 `qhd`에 같은 뒤붙임을 쓴다. 비교 명령은 PitBull4와 Quartz의 지정 창을 바꾸고 기본 해상도·파티·테마·대화창 및 Quartz 모듈의 켜짐 설정을 유지한다. 기본 프리셋 이름 `uhd`로도 V1 배치가 돌아온다. 비교에 해당하는 창의 개인 편집값은 미리 기존 `/dfp save`로 저장할 수 있다.

| 연결된 부분 | 확인 결과 |
|---|---|
| 요청을 받는 프리셋과 저장값을 쓰는 쪽 | 정상 명령, 다시 불러오기, 비교 V1 및 일반 V1까지 왕복했다. 사용자가 추가한 이름의 창·배치와 파티, 모듈 켜짐 설정이 보존됐다. |
| 실제 Lua를 불러 쓰는 핏불·Quartz와 전투 경계 | 네 화면에서 세 배율씩 실제 배치 코드를 실행했다. 시전 시작·종료, 차단 표시, 오라 최대 배치, 불필요한 스윙 갱신이 끝나는 흐름을 대조했다. |
| 사격과 근접 평타 공용 게이지 | 근접과 원거리에서 시작·중간·만료·다음 주기의 시간과 채움 값이 갱신됐다. 보조무기 입력을 건너뛰고 제한된 값에 접근하지 않으며 비정상 시간과 모듈 끄기를 처리했다. |
| 기준 입력, 파일 복제와 실행 시험 | Core 109/109, 첫 시작 29/29, 시전바 16/16, 핏불 연결 20/20, 핏불 원본·모듈 6/6, 등록부 검사를 통과했다. 패치 6개, 변경 없는 애드온 폴더 21개를 재현해 불일치 0개다. 원본 ZIP과 패치 선언을 읽는 추출 도구의 결과도 저장 목록과 일치했다. |

`Collection/tests/layoutv2/`의 네 자동 시험 파일과 두 접속 확인표에 결과 조건을 남겼다. 독립 검수에서 연계·사용자 요구·경계 상황을 대조해 고칠 결함을 발견하지 않았다. 빌드 도구가 새 프리셋을 포함하는 경로도 확인했다. 실제 포에버 전투에서 게이지 채움과 시야가 맞는지는 사용자가 직접 확인할 부분이다. 10:00 사용자 지시로 검증된 소스와 기록을 같은 이름의 GitHub 작업 브랜치에 올린다.
