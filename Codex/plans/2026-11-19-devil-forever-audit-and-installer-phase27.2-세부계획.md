## 구현 단위와 기록

- 경로와 승인 입력을 교차 검증한다. 사용자가 고른 게임 에디션과 해당 ZIP을 확인하고, 실제 드라이브·보호 경로·대소문자·Windows 파일 이름·링크·ZIP 파일형식을 검사한다. 게임 경로에서 사용하는 입력은 게임 실행 파일의 위치와 `Interface/AddOns`다.
- 상태 조회와 미리보기에서 현재 파일, 기존 장부의 소유 기록, 두 단독판이 남기는 폴더, 사용자 선택을 대조한다. 미리보기와 적용 사이의 입력 변경을 명시적으로 감지한다. `WTF`, 무관 애드온, 모르는 반대 판 폴더는 보존한다.
- 준비·백업·실제 파일 이동과 활성 장부 기록을 같은 볼륨의 한 작업으로 수행한다. 준비본과 설치 위치의 파일별 해시, 원본 백업의 해시, 실행 ID와 복원 지점을 연결한다. 동일 대상 쓰기는 차례로 수행한다.
- 복원과 제거는 같은 실행 엔진·기록을 이용한다. 이전 내용은 있는 위치와 해시를 검증하기 전에 움직이지 않는다. 오류가 발생하면 현재 위치와 회복 가능한 기록을 보여 준다. 끊긴 작업을 다시 실행할 때는 방금 확인한 실제 상태를 사용한다.

## 구동과 검수

실제 승인 ZIP, 읽기 전용 원본과 새 시험용 `_forever_` 폴더를 사용한다. 한국어·공백이 포함된 경로, 신규 대상, 이미 수정된 애드온, 무관 애드온, `WTF` 샘플의 파일별 해시를 기록한다. 게임 실행 자체는 별개 단계에서 한다.

구조 코드의 독립 검수는 실제 명령이 통과한 뒤 연계·뜻·적대 관점으로 수행한다. 사용자가 고른 경로와 옵션부터 ZIP·준비 경로·관리 대장까지 이어지는 연결을 대조한다. 시험의 기본값과 프로그램의 결과는 실제 호출로 확인한다. Stage 55의 강제 종료와 권한·디스크 실패는 여기서 확인한 정상 적용·복구 흐름을 이어서 시험한다.

## 경계

일반 Windows 계정에서 오프라인으로 수행할 코드다. 게임의 실제 프로필·공개 배포는 기존 승인 경계를 따른다. 화면 배치와 사용자용 단일 실행 배포는 Phase 27.3에서 이어진다.
