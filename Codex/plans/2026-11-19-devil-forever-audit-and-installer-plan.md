## Summary

이전 Codex 작업, Claude 작업, 현재 통합본을 같은 기준으로 검토한다. 사용자가 확정한 요구를 출발점으로 삼고, 각 요구가 기능 트리·Lua·프리셋·실제 ZIP·실사용 관측까지 이어지는지 반증 시험으로 확인한다. 결과에 따라 Master Plan과 기능 지도를 갱신하고 그 기준 묶음을 설치기에 연결한다.

설치기는 **Windows x64용 C#/.NET 10 자체 포함 실행 파일과 기존 애드온 ZIP을 한 배포 묶음으로** 제공하는 방식을 권장한다. Python은 애드온 ZIP을 작성하고 시험하는 현재 개발 환경에서 계속 쓴다. 사용자 PC는 설치기를 실행할 때 Python이나 별도 .NET 런타임을 준비할 필요가 없도록 만든다. 청정 환경 실행으로 이 요건을 확인한다. ## Phase Range

**26 전면 재검토.** 요청 대장과 기능별 실제 파일을 맞추고, Claude 작성·Codex 이전 작성·이번 통합을 동일한 기준으로 반증 시험한다. 계정 설정 쓰기, 목업 좌표의 실제 사용, 일반 빌드와 지정 빌드의 일치부터 확인한다. 승인 범위 안에서 확인된 결함은 고쳐 원래 반증 조건과 영향 범위를 다시 실행한다. 중대·중간 결함을 닫고 배포 기준과 Master Plan을 확정한다. 권한이나 범위 결정을 요구하는 결함은 그 항목의 출하를 보류한다.

**27 설치기.** 첫 실험에서 실행 파일의 의존성, 운영체제, 크기, 관리자 권한 없이 실행과 사용자 지정 경로를 확인한다. 엔진과 화면은 검증된 ZIP 계약을 공유한다. 설치·갱신·검증·직전 상태 복원·관리 파일 제거까지 같은 엔진을 사용한다.

**28 검증과 인계.** 고장 주입, 깨끗한 Windows x64, 실제 게임 관측을 각자 기록한다. 최종 게임용 묶음의 해시를 설치기 카탈로그와 연결하고 사용자용 설치·복원 안내를 함께 남긴다.

## Non-goals

- 게임 본체·런처 이동, 시스템 Python·별도 런타임 설치, 전역 환경변수 변경, 관리자 권한 요구를 기본 설치 범위에서 제외한다.
- 인게임 옵션의 전체 통합 편집기, 개인 `WTF` 자동 덮어쓰기, 애드온 설정의 자동 변환, 여러 게임 판 동시 적용을 제외한다.
- 첫 배포는 오프라인 Windows x64 로컬판이다. 자동 업데이트 서버, 게시, 코드 서명 도입, Arm64·Mac 지원은 별도 배포 결정으로 둔다.

### 설치 동작

1. **대상 점검.** 사용자가 고른 또는 확인한 Forever 게임 루트에서 실행 파일과 `Interface/AddOns`를 대조한다. 설치나 복구 중인 같은 대상, 실행 중인 게임, 권한·디스크 공간·설치 기록 이상을 점검한다. 다른 게임 판과 경로가 섞이면 그 위치에 쓰지 않는다.
2. **개인값·충돌 확인.** ZIP과 승인 배포 카탈로그의 해시, 압축 경로, 대소문자 충돌, 기존 파일 소유권을 검사한다. 같은 이름의 미관리 폴더를 교체하려면 별도 선택과 검증 백업이 필요하다. PitBull4판과 FUF판 사이에서 전환할 때는 소유권과 해시가 확인된 이전 판 전용 폴더를 백업으로 이동한 뒤 새 단독판을 적용한다. 미관리·수정된 반대판 전용 폴더가 있으면 보존하고 해당 설치를 막는다. 더 새로 설치된 판은 일반 갱신에서 보호한다. 이전 버전으로 돌아가는 작업은 검증된 복원 기록을 사용한다. 비교 ZIP은 내부 실사용 시험용으로 유지한다.
3. **변경 미리보기.** 기존·추가·교체·충돌·복원 가능 여부를 폴더별로 표시한다. 확인 화면과 읽기 전용 CLI는 실제 쓰기 계획과 같은 데이터를 사용한다. 미리보기 이후 게임·설치 기록·파일이 바뀌면 계획을 다시 계산한다.
4. **검증된 적용.** 대상 볼륨의 별도 준비 위치에 풀고 모든 관리 파일의 SHA-256을 검사한다. 교체 전 원본과 실행 기록을 남기고 최종 위치에 적용한다. 원자적 단일 작업처럼 가정하지 않는다. 파일 이동 사이에 종료·잠금·디스크 오류가 생겨도, 기록에서 어느 폴더가 교체됐고 무엇이 남았는지 찾아 원복하거나 복구를 계속한다. 설치 성공 표시는 최종 파일 검증과 기록 확정 뒤에 낸다.
5. **재검증·복원·제거.** 검증은 읽기 전용이다. 복원은 직전 성공 실행의 대상과 백업으로 제한한다. 제거는 소유 기록과 해시가 맞는 관리 파일만 처리하고 사용자 수정분·다른 애드온은 남겨 사유를 보여 준다. `WTF`는 기본 설치·갱신·제거에서 수정하지 않는다. 게임 안 설정 되돌리기와 수동 전체 백업은 기존 안내를 연결한다.

첫 화면에 게임 경로·현재 설치 버전·선택판을 표시한다. 기본 배포에는 PitBull4 ZIP을 동봉하고, FUF 단독판은 같은 실행 파일에서 승인 해시와 맞는 로컬 ZIP을 선택하는 방식으로 제공한다. 두 판 모두 FHD·QHD·4K와 테마 13종을 포함하며 실제 선택은 게임 안 Core에 둔다. 설치 진행 화면은 단계와 실패 이유를 보이며 지원 요청에 첨부할 복사 기록에는 이름·계정·전체 개인 경로를 가린다.

## Assumptions

- 첫 사용자 배포 대상은 지원되는 Windows 11 x64 일반 계정이다. 다른 운영체제는 실제 필요와 깨끗한 환경 시험이 확보된 뒤 지원 목록에 넣는다.
- Step 49에서 Windows x64 라이브러리를 자체 포함한 시험 실행 파일을 일반 사용자 토큰으로 실행했다. 완성 설치기의 깨끗한 Windows 사용은 Step 56에서 검증한다. [도구 확인 결과](../results/Step%2049%20%E2%80%94%20Windows%20단일%20실행%20파일%20검증.md)
- 기존 세 ZIP은 감사와 개발 입력이다. 최종 게임 동작과 묶음의 수용 여부는 Step 41 관측과 재검토 결과가 정한다.
- 사용자 경로 쓰기는 승인된 게임 폴더와 선택한 설치 기록·백업 위치에 한정한다. 개발은 먼저 격리된 시험 대상에서 한다.
