## Implementation Changes

- 대장 경로는 `Codex/results/REQUEST_LEDGER_codex-phase25.md`다. 추적 문서에서 Codex의 요청을 가리키는 항목만 새 번호와 대장으로 연결한다. 번호가 같은 Claude 요청은 그 대장의 번호를 사용한다.
- Step 40 통합 기록은 `Codex/results/`에 출처와 함께 보관하고 링크를 새 자리로 잇는다. Phase 29.1·29.2 문서와 기계 판독 파일, Step 60·61을 대조해 필요한 자료를 게시한다. 공개 가능한 근거가 로컬에만 있을 때는 파일을 옮긴다. 개인 경로·백업·원본 확인이 어려운 곳은 링크 없이 ‘로컬 전용’으로 표기한다.
- Aurora 권고는 미포함이다. 낱개 틀은 승인 이미지에서 같은 원본 조각을 만들고 같은 순서로 그리는 방식으로 비교한다. 특히 단축바에서 채팅으로 이어지는 연결부, 오른쪽 채팅창의 문양과 테두리, 테마별 모서리·재질을 대조한다. 현재 낱개 경로와 승인 합성판은 각각 비교 기준으로 둔다.
- 적응형 배치는 물리 화면과 실제 UI 배율을 입력으로 받아 하단에서부터 쌓는 방식으로 설계한다. FHD·QHD·UHD 버튼은 48·56·80픽셀, 간격은 2픽셀, 안쪽 여백은 6·6·8픽셀을 처음 대조할 값으로 둔다. 채팅 글자 18·22·28픽셀, 셋째 창의 문양 자르기와 읽기 영역, 전투 중 지연과 수동 프리셋 전환도 입력에 둔다.
- Grid2는 파티와 공격대가 공통으로 쓰는 왼쪽 위 기준점을 검토한다. PitBull4 적 소환수는 대상 근처의 적군 정렬을 잇고, 주술사 토템은 플레이어 근처에서 남은 시간을 읽을 수 있게 둔다. 세 해상도에서 파티와 소환수 조건을 따로 도식화하고 같은 화면의 시전바·버프·행동 단축바와 겹치는지 비교한다.
