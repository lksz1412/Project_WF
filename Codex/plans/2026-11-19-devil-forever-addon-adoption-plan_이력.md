# 상위 애드온 채택 검토 계획 이력

## 2026-11-19 · Phase 29.1–29.2

- 2026-11-19 두 순위 상위 20위씩을 확정하고 실제 0.1.1 ZIP 두 개를 설치 카탈로그와 대조했다.
- 2026-11-19 사용자의 성능 우선 의견을 반영했다. 기존 구성에 없는 중요 기능과 확인 가능한 실행 비용을 기본 포함 후보의 조건으로 적었다. 자체 Lua 성능 검수는 별도 요청에 따라 아스트라에 읽기 전용으로 의뢰했다.
- 2026-11-19 분류 뒤 고도화 요청으로 29.1–29.2 검토 실행을 승인받았다. [사용자 요청 대장](../results/REQUEST_LEDGER_phase29.1.md)
- 고유 30개의 포에버 배포 근거를 대조하고 선택 설치 7개의 최소 구성을 정리했다. 독립 검수에서 Questie의 이름표·대상 프레임 표시를 발견해 추가 설정을 명시했다. 재검에서 남은 결함 0건이다. [29.1 결과](../results/PHASE_29.1_addon-evidence_RESULT.md) · [29.2 결과](../results/PHASE_29.2_addon-adoption_RESULT.md)

## 2026-11-19 · Phase 29.3

- 자체 성능 개선 세 건과 로컬 묶음 검증을 제시하고 사용자 실행 승인을 받았다. [요청 대장](../results/REQUEST_LEDGER_phase29.3.md)
- 첫 독립 검수에서 찾은 소환수 예약 유실을 고쳤다. 재검, 전체 ZIP 대조, 신규 설치, 두 판의 갱신과 복원을 확인했다. [29.3 결과](../results/PHASE_29.3_runtime-performance_RESULT.md)
- 기존 동봉 애드온과 같은 기능 후보를 비교할 순서를 저장했다. 기능별로 최선 후보를 고르고 다른 후보의 검증된 장점을 적용한다. 선정된 코드의 반복 비용도 재현된 범위에서 줄인다.

## 2026-11-19 · Phase 29.4

- 11개 기능의 첫 로컬 비교와 독립 검수를 마쳤다. SexyMap 좌표 조회와 Experience Forever 퀘스트 목록 조회의 수정안을 새 시험 폴더에서 검증했다. [결과](../results/PHASE_29.4_bundled-addon-comparison_RESULT.md)
- PitBull4와 FUF의 호출 수가 조건마다 다르므로 기본판과 비교판을 유지했다. 실제 프레임 시간 비교는 한 접속에 모았다.

## 2026-11-19 · Phase 29.5

- 0.1.4 로컬 시험 묶음에 Quartz 새 기본 프로필의 오라 설정과 공용 프로필 보존 정책을 반영했다. [설정과 ZIP 기록](../results/Step%2070%20%E2%80%94%20Quartz%20오라%20기본값과%200.1.4%20시험판.md)
- 파일 단위의 기능 시험과 별도 프레임 시간 측정 도구를 준비하고 실제 게임 확인 절차에 연결했다. [29.5 결과](../results/PHASE_29.5_local-runtime-trial_RESULT.md)
