# Phase 29.2 채택 권고와 독립 검수

2026-11-19 · Phase 29.1 결과를 입력으로 사용

| Step | 예상 | 결과와 확인 조건 |
|---|---|---|
| 61 | 40–70분 | 후보 30개의 최종 권고와 선택 설치 조합. 게임 기본 기능, 현재 구성과 기존 선택을 근거로 사용. 개인별 선택의 최소 폴더와 맞물리는 설정을 기록 |
| 62 | 25–45분 | 독립 검수. 두 순위 40개 항목과 30개 권고가 빠짐없이 연결되는지 확인. 근거가 허용하는 범위와 실제 구동 미측정을 구분 |

선택 후보 7개에 설치 조합과 개인 설정을 제시한다. Questie와 QuestieDB, DBM 본체와 콘텐츠 모듈은 함께 대조한다. TradeSkillMaster는 데스크톱 보조 프로그램이 필요한 가격 데이터 흐름을 표시한다. DungeonJournal과 AtlasLoot는 필요한 기능을 중복 제공하는 지점을 확인한다. GTFO의 적용은 DBM 등 기존 경보와 한 장면에서 겹치는지에 달려 있다.

게임에서 확인할 때는 같은 화면 배율, 캐릭터, 장소, 동작과 시각 구간을 유지하며 후보 하나씩 실행 여부를 비교한다. 평균 초당 프레임 수만으로 판단하지 않고 해당 창의 초기 지연, 지도 열기와 닫기, 전투 프레임 시간, 오류와 설정 보존을 함께 기록한다. 설치와 게임 적용은 이번 실행에 포함하지 않는다.
