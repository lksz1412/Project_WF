## 화면과 명령의 관계

화면은 대상과 판을 먼저 정한다. 기존 애드온·충돌을 구별해 미리보기에 보여 주고, 같은 이름의 바꿀 수 있는 폴더는 사용자가 직접 선택할 수 있게 한다. 기존 사용자 값이 달라진 경우에는 이유와 해당 폴더를 알려 준다. 적용·일치 검증·복원·제거에 같은 상태 목록과 성공 판정을 사용한다. 진행 중 대기 또는 처리 결과를 보여 주고 실패 뒤 다시 할 수 있는 명령을 명시한다.

명령줄은 표준 출력에 상태 또는 JSON을 출력한다. 실행 실패 이유나 진행은 표준 오류에 보낸다. 스크립트에서 결과와 실제 종료 코드를 각각 확인한다. 실제 사용자 폴더는 로컬 결과에만 표시하고 복사용 결과에는 관리 폴더의 이름과 판·작업·상태로 남긴다.

## 배포본

.NET 10 Windows x64 자체 포함과 단일 실행 파일을 사용한다. 빌드 결과는 승인 입력을 담은 `DevilForeverSetup.exe`, 기본 PitBull4 ZIP, 짧은 실행·복원 안내로 묶는다. FUF 단독판은 해시가 고정된 선택 ZIP이다. 같은 접속 비교용 ZIP은 게임 확인 경로에 둔다.

검수에 사용한 배포본의 바이트, 전체 해시, 실행 결과, 시스템 도구와 Python 설치 없이 호출하는 진입 경로를 기록한다. 새 배포본은 이전 파일과 분리해 전달한다. 청정 Windows 실행은 Step 56에서 확인한다.
