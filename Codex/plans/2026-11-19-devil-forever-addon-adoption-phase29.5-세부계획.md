# Phase 29.5 시험판 최적화와 프레임 시간 측정 준비

2026-11-19 · 0.1.3 로컬 시험 ZIP과 기능 시험 결과를 기준으로 진행

| Step | 예상 | 완료 조건 |
|---|---|---|
| 70 | 15–30분 | 기존 Quartz 프로필을 보존하고 새 프로필에서 중복 오라 막대만 끈다. 실제 0.1.4 시험 ZIP 세 개에서 등록·기능·기존 파일을 대조한다 |
| 71 | 15–25분 | 게임 기본 상태와 모음집에서 같은 도구로 프레임 시간을 잴 수 있게 준비한다. 측정을 켰을 때만 프레임 콜백을 사용하고 중간값과 느린 구간을 기록하는지 Lua에서 확인한다 |
| 72 | 10–20분 | ZIP의 실제 소스로 기능과 성능 회귀를 돌리고 독립 검수한다. 두 판과 기본 게임을 한 접속에서 비교할 준비와 확인 순서를 기록한다 |

## 범위와 영향

Core의 로드 목록·생성 등록표·Quartz 기본값의 새 프로필 경로를 동봉본 기준으로 확인한다. SexyMap·Experience Forever의 앞선 개선을 포함한 0.1.3의 승인 시험 파일을 기준으로 삼아 0.1.4 시험 ZIP과 확인 기록을 별도 폴더에 만든다. 프레임 시간 측정 도구는 기본 게임과 모음집에서 같은 상태로 쓸 수 있도록 별도 폴더로 제공한다. 게임 경로 적용, 원격 게시, 설치기 업무는 이번 실행과 별도다.

## 검증 기준

| 대상 | 검수 갈래 | 관점 |
|---|---|---|
| Quartz 기본값과 시험 ZIP | 코드 국소 변경 | 새 프로필 기본값, 기존 모듈 선택, 시전 기능, 등록표와 로드 목록, 압축된 파일의 정확성 |
| 프레임 시간 시험 도구 | 코드 구조 변경 | 슬래시 진입, 종료·취소·재시작, 통계 계산, 멈춘 동안의 비용, 모음집 밖에서도 동작하는지 |

## 진행 경계

기존 작업 파일을 보호하기 위해 이미 검증한 ZIP을 읽고 새 로컬 사본에서 진행한다. 기존 도구와 시험 환경을 사용한다. 네트워크·새 설치 도구 없이 준비하며 생성물은 전수 재대조한다. 실제 게임에서만 확인할 프레임 시간과 표시 정확도는 미측정으로 남기고 접속 때 실행할 조건을 정리한다.
