# Devil Forever 인계 v0.1.1 — 로컬 설치 시험판 준비

## 1. 받은 지시

기존 `D:\Projects\Project_WF`의 Claude 인계와 이전 사용자 설계를 이어서 작업했다. R150의 마스터 플랜 구체화에 이어 R151 `ㄱㄱ`는 계획의 로컬 실행 승인이다. 게임 폴더 실제 적용과 외부 공개는 계획 §11의 별도 승인 범위다. [요청 대장](../results/REQUEST_LEDGER_phase26.md) · [마스터 플랜](../plans/2026-11-19-devil-forever-audit-and-installer-plan.md)

## 2. 완료한 작업

Step 44–48에서 Claude와 이전 Codex 결과를 같이 검토했다. 채팅 구독과 입력 기록 보존, 자동 배치, FUF 비교 배치와 Hekili 안내를 보정했다. 기본 PitBull4, 대체 FUF, 한 접속 비교 ZIP을 새 해시로 고정했다. 화면 프리셋은 FHD·QHD·UHD, 테마는 13종이다. [기능 트리](../../Collection/data/feature-map.md) · [Phase 26.2 결과](../results/PHASE_26.2_functional-audit_RESULT.md)

Step 49–55에서 Windows x64 설치기, 단일 실행 파일, 설치·검증·복원·제거, 두 단독판 전환과 중단 뒤 처리까지 검증했다. Step 58은 0.1.0 로컬 전달 기록이다. Step 59에서 승인한 채팅 외관을 실제 ZIP 세 개와 Windows 설치기에 넣어 0.1.1을 만들고, 0.1.0에서 갱신하고 복원했다. [현재 0.1.1 시험판과 확인 결과](../results/Step%2059%20%E2%80%94%20채팅%20그림과%20설치%20묶음%20갱신.md) · [0.1.0 전달 기록](../results/Step%2058%20%E2%80%94%20로컬%20시험판%20전달.md)

## 3. 미완료 항목

- Step 56의 별도 청정 Windows. 현재 PC의 일반 사용자 토큰과 빈 런타임 검색 경로에서 종료 0을 관측했다. [현재 호스트 확인](../results/Step%2056%20%E2%80%94%20현재%20Windows%20격리%20확인과%20청정%20환경%20대기.md)
- Step 57의 실제 게임 파일 적용과 최초 한 접속 확인. 승인 후 4K 글자, 실제 배율, 전투·채팅·파티·공격대와 두 유닛 프레임을 한번에 관측한다. 사용자는 평소 거리에서 4K 퀘스트 글자를 읽을 수 있는지 판단한다. [한 접속 확인표](../../References/codex-verify/one-session-review.md)
- Step 58의 최종 수용 판정. 현재 로컬 시험 ZIP과 EXE는 위 확인을 위한 기준 파일이다. 네 번째 해상도 이름과 4K 단독 배포 여부는 기존 사용자 결정을 기록할 항목이다.

## 4. 재개 시 주의점

현재 D 저장소와 실행 대장을 먼저 읽는다. 비교 ZIP은 설치기 카탈로그의 단독판 항목과 별개다. 시험 중 유닛 프레임은 PitBull4부터 사용하고, 동일 접속에서 바꿀 때 FUF 전용 비교 프로필을 만든다. 실제 게임을 열기 전 승인된 경로의 백업·해시를 확인한다. 기존 작업자의 수정·이전 ZIP은 비교 기준으로 남아 있다. [실행 대장](../results/PHASE_26-28_EXECUTION_LEDGER.md) · [설치 계약](../../Collection/Installer/Contract.md)
