# 원본의 84칸을 유지하고 아래부터 쌓는 첫 배치안

**큰 버튼은 80px, 하단 묶음은 8열×3행으로 잡았습니다.** 원본의 긴 36칸 한 줄, 하단 24칸, 좌우 센터바 12칸씩을 모두 유지합니다. 버튼과 바닥 여백부터 계산한 결과 검정 하단부 높이는 392px입니다. 화면 전체 비율로 늘린 값이 아닙니다.

4K는 사용자 확인 사항입니다. 이번 오프라인 작업판은 3840×2160으로 두었으며 실제 Windows·게임의 정확한 해상도와 UI scale은 아직 측정하지 못했습니다. 아래 수치는 **첫 제안의 고정 pixel 값**입니다. 실제 게임에서 적용·검증한 값과 구분합니다.

## 버튼을 놓은 뒤 하단 높이를 결정합니다

| 바닥부터 쌓는 순서 | 높이·간격 | 바닥 기준 상단 |
|---|---:|---:|
| 얇은 정보줄 | 32 | 32 |
| 여백 + 작은 메뉴·가방줄 | 8 + 56 | 96 |
| 여백 + 하단 8×3 버튼 | 8 + (80×3 + 4×2) | 352 |
| 패널 위 여백 + 검정 rail | 8 + 32 | 392 |
| 원본의 긴 36칸 한 줄 | 80 | 472 |

하단 24칸은 **668×248px**입니다. 그 오른쪽에 **328×328px 미니맵**, 이어 오른쪽 채팅 영역을 붙입니다. 왼쪽의 넓은 검정 구획 두 개도 유지하고, 새 잡다한 기능으로 채우지는 않습니다. 원본에서 하단 묶음은 712×263px, 미니맵은 약325×331px로 관측됐습니다. 버튼을 조금 정돈하면서 접합 관계를 살린 안입니다.

## 원래 배열과 제안을 구분했습니다

| 영역 | 원본 이미지 관측 | 첫 제안 |
|---|---|---|
| 긴 행동단축바 | 36열×1행, 버튼 외곽 약82px | 36열×1행, 슬롯 외곽80px·간격3px |
| 하단 버튼 묶음 | 8열×3행, 버튼 약85px | 8열×3행, 슬롯80px·간격4px |
| 좌우 센터바 | 각각4열×3행, 버튼 약70px | 각각4열×3행, 슬롯68px·간격4px |
| 검정 하단부 | 높이 약393px, 검정 fade·구획선 | 내용으로 산출한392px, fade·Devil2 테두리 참조 |
| 미니맵·채팅 | 하단 묶음→미니맵→오른쪽 채팅 접합 | 같은 순서·위치 관계 유지 |
| 체력·자원창 | 큰 은색/파란색 창1개; 정확한 player/target 역할 미확정 | 본인 창 배치 + 별도 대상 창 자리 제안; 추가 대상 예시는 점선으로 구별 |

회수 설정도 이 배열을 설명합니다. Dominos의 **1·6·5번은 12칸씩 옆으로 접합**되고, **3·4번은 4열×3행씩 접합**, **9·7 및 8·10번은 2열×3행씩 접합**됩니다. 원본의 긴 줄을 빼거나 큰 중앙 미니바 하나로 바꾸지 않았습니다. 정확한 소스·행과 소비 코드의 연결은 `Codex/results/layout-design/source-comparison.md`에 기록했습니다.

원본에서 보이는 큰 상태창은 한 개뿐입니다. 회수한 PitBull 설정에는 본인과 대상이 모두 있지만, 그 사실만으로 원본 그림에 대상 창이 보인다고 하지 않았습니다. 제안의 본인·대상 창은 각각512×116px이며, 긴 버튼줄 상단에서176px 띄운 높이에 둡니다. 현재 대상이 없을 때의 표시와 실제 체력·마나 값은 추후 게임에서 확인할 부분입니다.

## 글자와 검정 외형을 먼저 읽을 수 있게 잡았습니다

버튼 슬롯80px 안의 아이콘 영역은64px, 키 글자는22px, 체력·마나·지역 글자는24px를 첫 기준으로 정했습니다. 키 글자는 밝은색과 작은 어두운 바탕을 사용합니다. 이 두 색의 계산 대비는17.45:1이며, 이것이 실제 아이콘·거리·긴 단축키 문자열의 가독성 시험을 대신하지는 않습니다.

Onyx Classic 테두리, Devil2 구획선, Glamour7 상태바와 동봉된 좌우 장식 파일을 참조합니다. 우측 장식은 원본에서도 일부가 가려져 있으므로 숨은 모양을 새로 복원했다고 표현하지 않습니다. 장식은 입력을 받지 않는 요소로 두고 버튼 끝과의 작은 겹침만 허용합니다.

이 제안의 빈칸과 아이콘 밀도는 원본을 참고하되, 아이콘은 중립적인 자리표시로만 그립니다. 주문·특성·키를 배정하지 않습니다. 원본의 채워진 칸26개는 공개 이미지의 상태일 뿐 사용자의 주문 목록이 아닙니다. 미리보기의 ‘키’, ‘체력’, ‘마나’, ‘미니맵’도 배치 예시입니다. 사용자 매크로와 키 설정은 열거나 바꾸지 않았습니다.

토템·효과 알림은 긴 줄 위에 작은 예약 영역만 두었습니다. 시전바도 현재 Quartz의 loaf 설정 부재를 유지해 예약 위치만 정했습니다. 새 알림 도구·meter·broker·party 기능을 배치 때문에 추가하지 않습니다.

## 현재 확정한 것과 남은 확인

**확정:** 원본3840×2160 JPEG, 이미지 판독 기록의 근사 배열, 회수 설정의 칸 수·접합, 제안 전체84칸·좌표 범위·입력 요소 충돌0. **설계 제안:** 80/68px 버튼,22/24px 글자,392px 하단부와 본인·대상 배치. **근거 미발견:** 원본의 별도 대상 창, 실제 개인 키 배정, 원본 Quartz loaf. **미검증:** 실제 게임 해상도·UI scale, 보는 거리에서의 크기·한글·긴 키 글자, 현재 애드온 설정 수용·입력·전투·재접속 작동.

오프라인 미리보기는 `layout-spec.json`의 좌표로 기계 생성합니다. 작업판 폭이 달라져도 버튼 크기·행 간격·바닥 적층 높이를 일괄 비례 변경하지 않습니다. 실제 게임의 UI 좌표 변환은 이후 실측값을 사용합니다. 이번 문서와 미리보기는 게임 구현 완료 판정이 아닙니다.
