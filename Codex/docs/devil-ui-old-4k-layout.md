# 옛 Devil 블랙 하단 UI의 4K 배치 설계

상태: A1 설계·자체 G5 30/30 확인 완료, 후속 렌더 대기. 새 배치 PNG는 아직 생성하지 않았다. 이 문건은 이후 렌더 제작자가 소비할 제안이며, 실제 게임의 배치·입력·분류·전투 검증이나 사용자 정확 픽셀 승인이 아니다.

현재 목표는 **idx45의 실제 네 번째 샘플**이다. 왼쪽 대화창 둘과 오른쪽 대화창 하나, 중앙 아래 8×3 버튼 묶음, 그 오른쪽 사각 미니맵, 긴 윗줄·검은 가로 띠·얇은 구분선·양끝 장식을 유지한다. idx11218의 오른쪽 미터기는 제외한다. 기존2022 배치안은 동결 상태이며 이번 설계에 재사용하지 않았다. R20–23·R33–34와 현재 Step5 발주가 기준이다.

## 버튼 크기에서 아래 높이를 계산한다

**버튼 외곽80픽셀·아이콘64픽셀·안쪽 여백8픽셀·버튼 사이2픽셀**을 먼저 정했다.4K에서 아이콘과24픽셀 단축키를 함께 읽을 공간을 확보하는 A1 제안이다. 화면 폭을 먼저 채운 뒤 크기를 역산하지 않았다. 원형 Onyx 소스의 `Icon Width=32`와 `Normal Width=40`은 아이콘과 스킨 외곽을 구별하는 근거이며, 새80/64는 같은 부품 관계를 적용한 제안이다. 소스 좌표나 사진 전체를 확대했다는 뜻이 아니다.

## 기본 채팅과 외형 담당의 역할을 나눈다

기본 채팅은 **수신·송신·창별 분류·일반 입력**을 담당한다. 직접 제작 후보는 **세 반투명 패널·얇은 구분선·폰트·버튼/탭/입력 테두리·배치**다. 새 채팅 엔진을 만드는 계획이 아니다. 현재 소스의 외형 제어 기전은 가능성의 근거이며 새 코드·현재 API(Application Programming Interface, 애드온이 사용하는 게임 기능)·실제 작동을 보장하지 않는다. 기존 Prat 한 개를 외형 담당으로 쓰는 조건부 대안도 유지한다. R37의 질문을 custom 최종 선택이나 게임 코드·설치 승인으로 해석하지 않는다. 근거: 수용된 `forever-clean-chat-research.md:93–116`·`clean-chat-source-evidence.md`.

평상시에는 큰 제목·좌측 버튼더미·입력 테두리를 드러내지 않는 외형이다. 입력 중에는 기존 native 입력창을 각 패널 안의36픽셀 예약 띠에 놓는 설계다. hover·알림·스크롤 복귀·설정에 필요한 접근은 남겨야 한다. 구형1/2/3 또는1/3/4 ID나 길드·파티 등의 분담을 복사하지 않고 세 독립 역할과 실제 현재 필터를 보존한다. 키 편집·history·한글 조합·focus·잠금/저장은 실제 게임 시험 전 미검증이다. 기존 제품의 부가 메시지/저장 개입과 미독 Leatrix core의 한계도 Step4에서 바뀌지 않았다.

## 렌더 계약과 확인 상태

`layout-spec.json`은 canvas·고정 토큰·14역할·68행동셀의 외곽/아이콘/키 경계·z순서·alpha·샘플 글자·자산 ID를 담는다. 색 대비는 설계 토큰으로 먼저 계산했다. 처음 구분선색은 밝은 배경 대비2.73으로 하한3에 미달해 실제 색을 `#909294`로 바꿨다. 변경된 대비는3.38/5.87이며 본문은7.39, 키와 검은 stroke는18.43이다. 두께·하한을 낮춰 통과시키지 않았다. 실제 텍스트 픽셀과 복잡한 아이콘 위의 읽기는 이후 확인한다.

후속 제작자는 새 경로에서 이 명세와 자산 manifest를 소비해 실제3840×2160 PNG·하단 원배율 crop·키 라벨 crop·픽셀 검사·실행 영수증을 생성한다. source hash 불일치·없는 자산·글꼴은 임의 대체하지 않는다. 옛 Lua/EXE·2022 renderer는 실행하거나 재사용하지 않는다. 실제 생성·픽셀 확인 후 지정 판독자와 같은 Phase 검수자의10개 P4 관점으로 검증한다. A1은 이번에 렌더 코드나 PNG를 만들지 않았다.

|---|---|
| 원형 역할·선택 설정·자산 원문 연결 |자체 G5 확인,30/30. 최종 독립 수용은 이후 |

| 새 배치 PNG·실제 픽셀·새 렌더 판독·독립 P4 |미수행 |
