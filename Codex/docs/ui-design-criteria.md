# 화면 설계 기준

2026-11-19 · 테마 목업 13종 검토에서 정한 기준이다. 다음 화면을 설계하고 다듬을 때도 사용한다.

## 글과 버튼이 먼저 보이게 한다

- 실제 화면에서 쓰는 그림과 크기로 목업을 만든다. 채팅, 퀘스트, 이름표, 단축바에 글과 버튼을 넣어 평소 쓰는 모습으로 본다.
- 장식이 글줄이나 버튼 자리까지 밀고 들어오면 장식을 줄인다. 글이 길거나 여러 줄 쌓였을 때와 밝은 배경 위에서도 읽을 수 있는지 본다.
- 함께 쓰는 화면은 같은 해상도와 배율에서 나란히 놓고 본다. 지원하는 해상도마다 글자 크기와 배치가 실제로 쓸 만한지 확인한다.

## 테두리와 무늬

- 세로 테두리 폭은 둥근 모서리를 벗어난 곧은 구간에서 같은 높이로 재고, 양옆을 나란히 놓고 본다. 테마마다 두께와 둥근 정도에 조금씩 차이가 있어도 글이 잘 읽히면 된다.
- 오크의 오른쪽 세로 테두리는 4K 목업에서 49픽셀에서 31픽셀로 줄였고, 같은 높이의 다른 테마와 비슷해졌다. 이 수치는 이번 화면을 비교할 때 쓴 값이다.
- 채팅 무늬는 오른쪽 세 번째 창의 우하단에만 반투명하게 둔다. 원본의 왼쪽부터 가로 70%, 위쪽부터 세로 70%를 쓴다. 채팅 바탕 위에 무늬를 두고 그 앞에 테두리를 놓는다. 데빌 채팅창은 무늬 없는 검회색 바탕으로 둔다.
