# 귀마개 애드온 프로젝트 — 공개 사실 확인

조사 기준: 2026-11-18 한국 시각. 과거 프로젝트의 시작은 기간 제한 없이 찾았으며, 현재 관리 여부는 최근 12개월(2025-11-18~2026-11-18)의 공개 자료를 별도로 검색했다.

**사용자가 기억하는 ‘귀마개가 별도로 자체제작을 시작한 프로젝트’는 이번 공개 조사에서 특정하지 못했다.** 그 프로젝트의 제품명·개발자·출시 결과가 연결되지 않아 기능·현재 관리·포에버 지원도 미검증이다. 프로젝트가 없었거나 중단됐다는 결론은 아니다.

## 탐색 범위와 자체검수

귀마개·자체제작·개발·프로젝트·통합애드온·제작자 모집의 조합, 본인 YouTube·Potion·공식 카페 및 현재 포에버 관련 자료를 검색했다. 이름이 비슷한 UI, ElvUI 프로필, 다른 개발자의 제품을 같은 프로젝트로 묶지 않았다. 자동 생성된 설명 사이트와 관계없는 검색 결과는 사실 근거에서 제외했다.

기록된 확정 사실은 직접 확인한 본인 게시물·게시 설명 또는 별도로 총괄 작업자가 확인한 공식 배포 표기로 구분했다. 발견하지 못한 사실을 부재나 중단으로 바꾸지 않았다. 현재 게임 실행·설치·작동 검증은 하지 않았다.

자체검수 1회: 저장본 전체를 읽고 질문 네 가지, 출처별 작성자·역할, 날짜 종류, 인용 범위, 영상 접근 한계와 공식 지원 표기의 구분을 대조한다. 직접 인용은 출처당25단어 이내로 제한했다. 이 문서는 확인된 공개 사실표이며, 당시 프로젝트의 최종 경과를 규명한 보고서는 아니다.
