# 0.1.5 설치기 카탈로그에 넘길 값

현재 카탈로그는 0.1.2의 기본 PitBull4판과 FUF 선택판을 받는다. 다음 정식 판의 카탈로그는 출시할 ZIP을 확정한 뒤 그 파일에서 만든다. 이 문서는 0.1.5 배포 ZIP을 받는 쪽에 넘길 항목을 적는다. [현재 카탈로그](../../Collection/Installer/ReleaseCatalog.json) · [설치기 계약](../../Collection/Installer/Contract.md)

| 항목 | 채울 값 |
|---|---|
| 판과 버전 | `variant`, `version`, 승인판에서 쓰는 `interface` |
| 파일 식별 | 실제 ZIP 파일명, 전체 SHA-256, ZIP 바이트 수 |
| 압축 안에서 대조 | `Interface/AddOns/` 아래 일반 파일 수, 압축을 풀었을 때의 바이트 합, 최상위 애드온 폴더 목록 |
| 설치기 배포 | 승인 카탈로그를 실행 파일에 포함하고, 실제 ZIP에서 설치기의 읽기·미리보기로 판과 해시 대조 |

개발 브랜치에는 제3자 원본, 고친 부분의 diff, 빌드·시험 도구, 외관 원본과 검증 기록을 둔다. 0.1.5 사용자용 ZIP은 애드온이 읽는 Lua·TOC·텍스처 등 실행에 필요한 파일로 묶는다. 빌드 산출물에서 실제 TOC와 코드가 읽는 리소스는 유지한다. 테스트·진단·예비 그림은 개발 자료다. 비교판과 프레임 측정 ZIP을 따로 만들 경우 사용자용 설치 ZIP의 카탈로그에는 넣지 않는다.

0.1.4는 GitHub 시험판으로 확인됐다. 0.1.5 파일은 빌드와 사용자 확인 뒤 채운다. 현재 카탈로그 숫자를 복사해 임시 승인하는 대신, 생성 코드가 확정 ZIP을 읽어 값을 내도록 연결한다. 생성 뒤 변조된 ZIP, 비교 ZIP도 설치기에서 거부되는지 확인한다. [0.1.4 시험판](https://github.com/lksz1412/Project_WF/releases/tag/v0.1.4)
