안녕하세요.

예전에 클래식에서 쓰던 Devil UI 하단집중형이 마음에 들어서 잘 사용했었는데,

복귀했더니 애드온이 정상 작동을 안하길래 수정해서 사용중이던 것을 올립니다.

-------------------------------------------------------------------------------

와우를 설치한 폴더가 C:\Program Files (x86)\World of Warcraft\_classic_ 라면

_classic_\WTF\Account\계정번호\서버명\캐릭터명 (계정번호, 서버명, 캐릭터명 기록)


폴더안의 Cache, interface, WTF 폴더를 완전 삭제하시거나 다른 곳으로 옮겨두고,

업로드한 파일을 클릭하시면 위에 적어둔 와우클래식 기본설치 폴더에 설치됩니다.


이후에 기록해놨던 계정번호, 서버명, 캐릭터명으로 폴더명을 바꿔주면 작동됩니다.


다른 폴더에 설치한 분은 위 폴더로 찾아가서 설치폴더에 맞춰서 복사하시면 됩니다.



애드온 파일 용량이 커서 업로드가 안되서 구글 드라이브 업로드 후 링크 첨부합니다.
