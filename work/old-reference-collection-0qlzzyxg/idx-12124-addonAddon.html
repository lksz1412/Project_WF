설치방법 ←←← 설치법이 기존방법 에서 조금 변경 되었습니다. 확인!!


※ 꼭 이전버전 다운받으신 분들은 파일 모두 삭제 하시고 진행하세요~

※ [ 덮어쓰기 ] 하시면 위크오라, 플레이터 설정 등이 오류납니다.


1번) 다운로드 받은 파일을 설치하기 전에 본인의 계정번호를 알아야 합니다.
기존 와우 설치 폴더내 [ WTF ] - [ Account ] - 폴더안 [ SavedVariables ] 제외한 폴더이름 입니다.
* 본인의 계정번호를 따로 메모해 두세요!!


2번) 기존 와우 설치 폴더내에 [ Cache ] , [ Interface ] , [ WTF ] 3개의 폴더를 삭제해 주세요~
* 설치전 기존 [ Interface ] , [ WTF ] 폴더 백업을 권장 드립니다.


3번) 다운로드 받은 파일을 실행~ 설치시 꼭 경로를 [ World of Warcraft\_retail_ ] 폴더 까지만 지정 하셔야 합니다.
* 설치경로 - 예) C:\Program Files (x86)\World of Warcraft\_retail_


4번) 설치가 완료된 후 와우 폴더내 새로 생성된 [ WTF ] - [ Account ] - 폴더안 1번 ~ 3번 까지 수정해 주세요~
* 1번 수정 하시고 더블클릭 하시면 2번 , 3번 보시면 내용 이해 하실꺼에요~


5번) 게임 접속후 채팅창에 [ /reflux switch WideX ] 입력하세요~


6번) 채팅창에 [ /plater ] 입력후 [ 프로필 ] - [ 프로필 설정 열기 ] - [ 저장 중인 프로필 ] - [ MyNewProfile ]
선택 후 상단에 YES 버튼을 눌러 적용 완료해 주세요~


(기존 설치방법에서 변경되었습니다. 사용 프로필은 [ 기본값 ]이 아닌 [ MyNewProfile ] 입니다.)


7번) 이제 어둠땅 여정을 시작하시면 됩니다~^^



※ 재접속시 오른쪽 중앙 Grid2 애드온이 검정색 창으로 구동이 안될경우 [ /rl ] 입력해 주세요~


※ 설치방법 순서대로 꼭 진행해주세요~
