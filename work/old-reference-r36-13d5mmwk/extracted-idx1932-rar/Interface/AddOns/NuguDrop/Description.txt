◀ 기 본 설 명 ▶
   본 애드온은 각종 아이템의 획득정보를 툴팁하단부에 표시해 주는 애드온입니다.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
◀ 특          징 ▶
1. 툴팁 하단부에 각종 아이템 획득정보와 명예/평판정보를 확인할 수 있습니다.
2. 해당 아이템의 아이템ID 와 아이템Level 을 추가로 확인할 수 있습니다.
3. 미니맵 버튼을 지원하며, 자유로이 이동/고정이 가능합니다.
4. 자체 브라우저를 내장하여 언제 어디서든지 특정인던/평판/명예 아이템을 확인해 보실 수 있습니다.
    캐시에 아이템 정보가 없더라도 "클릭"을 함으로써 서버질의를 통해 아이템을 확인할 수 있습니다.
    (강제종료될 수 도 있습니다. -0-ㅋ)
5. 기본적으로 캐시데이터를 이용하여 아이템을 확인할 수 있으며
   부가적으로 아이템 사전과 연동하여 사용하면 더욱 빨리 확인이 가능합니다.
6. 가로폭이 넓은 폰트를 사용하는 유저의 경우 명령어를 이용하여 자신에게 알맞은 크기의
   브라우저를 설정할 수 있습니다.
7. 즐겨찾기를 활용하여 자신이 원하는 아이템만을 선별적으로 모아서 관리하실 수 있습니다.
    NuguDrop 즐겨찾기 Support 애드온과 병행하여 사용하시면
    각종 훔쳐보기 / 아이템 사전에서 손쉽게 누구드랍에 즐겨찾기를 하실 수 있습니다.
8. 랜덤 접두어가 붙는 아이템일 경우 자신의 캐시에 들어있는 아이템의 경우
   여러가지 접두어가 붙은 아이템들을 동시에 확인할 수 있습니다.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

◀ 각종 명령어 ▶
/누구드랍 /nugudrop /nd  :  기본사용법 출력

/누구드랍 사전 : 보유한 사전정보를 참조
/누구드랍 /캐시 : 캐시정보를 참조
/누구드랍 /폭 [100-150] : 리스트의 가로폭 기준치를 설정(기본:100)
/누구드랍 /미니맵 : 미니맵 아이콘 보기/감추기
/누구드랍 /원위치 : 미니맵 아이콘 위치 초기화
/누구드랍 /위치 [0~360] : 버튼을 미니맵 주변에 지정위치
/누구드랍 /고정(락) : 미니맵 아이콘을 고정
/누구드랍 /자유(이동) : 미니맵 아이콘을 자유롭게 이동 가능
/누구드랍 /아이템번호(itemID) : 아이템ID 를 보여줍니다.
/누구드랍 /아이템레벨(level) : 아이템Level 을 보여줍니다.
/누구드랍 /즐겨찾기(fav) : 즐겨찾기 창 보기/감추기
/누구드랍 /조회 : 아이템ID 를 직접 입력하여 링크확인 시도.
/누구드랍 /아이템수(갯수) : 현재 등록된 아이템수를 보여줍니다.

< 미니맵 아이콘 동작법 >
/누구드랍 좌클릭 : 브라우저 열기
/누구드랍 우클릭 : 즐겨찾기 열기
/누구드랍 휠버튼클릭 : 위치 초기화(미니맵 제일 왼쪽)
/누구드랍 Shift + 휠버튼클릭 : 아이콘 고정 토글
/누구드랍 Shift + 우클릭 : 미니맵 주변에 버튼 부착/이동
