== 재료천국(ReagentHeaven)은? ==

  여러 다른 재료알리미를 사용해보았지만, 불편해서 만들어본 애드온입니다.
  기존의 다른 재료알리미 계열은 수작업으로 재료데이터를 만들어서 작업을 했는데, 재료천국은 각 캐릭터가 배운 전문/보조기술, LootLink/TrainerSkills addon 등등의 자료를 바탕으로 데이터를 생성한 것입니다.


== 설치방법 ==

방법1) 다운받은 EXE파일을 실행하여, "재료천국 v0.99b 설치" 버튼을 누른다.
※ 위와 같이 풀리지 않을시에는, '방법2'를 사용하시면 됩니다.

방법2)  C:/Program Files/World of Warcraft 에 와우를 설치했다는 것을 가정했을 때, C:/Program Files/World of Warcraft/Interface/AddOns/ReagentHeaven 라는 폴더에 제가 올린 파일을 받으셔서, 설치해주시면 됩니다.


== 사용방법 ==

  * 다른 재료알리미처럼, 재료에 가져다대면 "사용되는 전문기술" 등이 툴팁에 나오게 됩니다.

  * 옵션(단축키를 지정하거나, "/rh 설정"을 입력)에서는 툴팁에 나오는 내용을 조정 가능합니다.
    - "재료천국 사용하기": 재료천국을 사용할지 여부를 결정합니다.
    - "조제법 자세하게 보여주기": 이 재료가 어떤 물건을 제작하는데 쓰이는지와 필요 숙련수치를 보여줍니다.
    - "자신에게 맞는 숙련도 색으로 보여주기": 해당 조제법 명을 자신의 캐릭터에 맞는 기술숙련도 색으로 보여줍니다.
    - "재료 재귀호출": 제작물이 다른 제작물의 재료이면, 계속 보여주면서 그 단계를 내려가게 됩니다. (실제로 사용해보시면 차이를 아실겁니다. +_+)
    - "완성품 재료 보여주기": 선택된 아이템이 재료가 아닌 완성품일 경우, 완성품을 보여주게 됩니다.

  * 재료천국창(단축키를 지정하거나, "/rh"을 입력)에서는 너무 내용이 길거나, 자신이 원하는 다른 종류를 검색하고 싶을 때 사용하는 곳입니다. 게임툴팁에 길게 나오는 것이 싫으신 분들은 옵션들을 거의 끄고, 이 창에서 보시는 것도 한 방법입니다.

  * 기타 재료천국 명령어
    - "/rh 범위설정 <스킬종류> <최소범위> <최대범위>" : 툴팁에 보여지는 스킬종류의 범위를 선택합니다. 기술의 숙련도 수치가 적혀있지 않은 것들은 무조건 보이게 됩니다.
     i.e. "/rh 범위설정 가죽세공 50 200" : 가죽세공 숙련도 50~200 사이의 목록만 보입니다.
