L191: ## Description
L192: 
L193: Please support my work on 【62†Patreon/GitHub†github.com】
L194: 
L195: By default BCM will allow you to drag your chat frames to the very edge of the screen, the remaining customization is done in BCM's modules which can be enabled or disabled at will.
L196: 
L197: ##### Configure
L198: 
L199: Type /bcm to configure BasicChatMods, a basic and modular approach to chat customization.
L200: ##### Combat Log Timestamps
L201: 
L202: Currently provided by Blizzard, right-click combat log tab > Settings > Formatting > Show Timestamp. Repeat this for every combat log, e.g. "My Actions", "What happened to me?".
