Masque Forever - 기본 버프/디버프 연동 v1

설치
압축을 푼 Masque 폴더로 Interface/AddOns/Masque 폴더를 교체한 뒤 /reload 합니다.
기존 Masque_Onyx, Masque_Dominos 폴더와 WTF 설정은 그대로 유지합니다.

적용
/masque의 전역 설정에서 스킨을 선택하면 기본 플레이어 버프·디버프 아이콘에도 적용됩니다.
개별 설정은 Blizzard Buffs 아래 버프 / 디버프 그룹에 표시됩니다.
숨겨진 기본 아이콘 슬롯도 등록하므로 전투 중 새로 생긴 오라에 적용됩니다.

수정 범위
Masque에 포에버용 기본 플레이어 오라 연동만 추가했습니다.
아이콘에 맞춘 별도 스킨 프레임을 사용하며 편집모드의 버튼 배치·크기,
기본 툴팁·버프 해제·중첩 수·남은 시간·점멸은 기존 처리를 유지합니다.
블리자드가 관리하는 비공개 오라 앵커는 변경하지 않습니다.
DevilUI나 다른 애드온은 이 ZIP에 포함하지 않습니다.

검증
실제 Masque 스킨·그룹·AceDB 코드와 기본 오라 생성·배치 코드를 사용한
로컬 검증을 통과했습니다. 실제 게임 실행 검증은 포함되지 않습니다.
