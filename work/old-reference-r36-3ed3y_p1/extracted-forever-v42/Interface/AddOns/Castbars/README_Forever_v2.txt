Castbars Forever-2

설치
- 압축을 풀어 나온 Castbars 폴더로 Interface/AddOns/Castbars 폴더를 교체합니다.
- 게임에서 /reload 하거나 다시 접속합니다. 기존 WTF 설정은 유지합니다.

수정 사항
- 신비한 화살 등 채널링 스킬: 가속도가 secret 값일 때 틱 간격 계산에서
  오류가 나던 문제를 수정했습니다. 이때 선택적 틱 눈금만 생략하며,
  시전바와 남은 시간 표시는 Duration API로 계속 표시합니다.
- 물 밖으로 나온 뒤 호흡 회복 바가 남던 문제를 수정했습니다.
  타이머 종료 이벤트가 오면 해당 바를 즉시 제거하고,
  회복이 완료되거나 타이머가 비활성 상태가 되어도 제거합니다.
- 시작/일시정지/종료 이벤트의 값을 직접 처리하여, 이벤트 시점에
  타이머 목록이 아직 갱신되지 않았어도 이전 바가 되살아나지 않게 했습니다.

검증
- 원본에서 secret 가속도 연산 오류를 재현했습니다.
- 수정본은 채널링/일반 시전/호흡 회복/설정 모드 관련 로컬 검증
  56개를 통과했습니다. 실제 게임 실행 검증은 포함되지 않습니다.
- 기존 프로필 구조, 기본 배치, 라이브러리 및 원본 Castbars.lua는 유지했습니다.
