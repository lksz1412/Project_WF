Broker_XPBar — 포에버 경험치·평판 동시 표시 v3
버전: 3.5.24-Forever-v3 / Interface 16001

설치
게임을 종료하고 Interface/AddOns/Broker_XPBar 폴더를 이 폴더로 교체하세요.
기존 설정 파일 BrokerXPBar_DB는 삭제하지 않아도 됩니다.
이 ZIP에는 Broker_XPBar와 자체 내장 라이브러리만 포함합니다.

이번 수정
스크린샷에서 툴팁의 스톰윈드 3180/6000(53%)는 정상 조회되고 있었습니다.
하단 ChocolateBar 글자는 별도의 '라벨 표시' 설정이 경험치 전용이어서
경험치만 출력되고 있었습니다. v2의 평판 조회/추적 수정만으로는
이 경험치 전용 라벨 설정이 바뀌지 않았습니다.

'경험치 + 평판' 라벨 모드를 추가해 둘을 함께 출력합니다.
사진과 동일한 입력값의 표시 예:
XP: 546/6.5k (8%)  ·  스톰윈드: 3.18k/6k (53%)

기존 경험치/평판 숫자 형식은 그대로 사용합니다.
기존 경험치 전용 또는 경험치 우선 라벨은 이번 버전 첫 적용 때 한 번만
동시 표시로 전환합니다. 이후 직접 경험치 전용으로 바꾸면 그 선택을 유지합니다.
추적 평판이 없을 때는 경험치만 표시하고, 평판이 바뀌면 이름과 수치도 갱신합니다.
기존 막대 그리기, 평판 데이터 조회 및 툴팁 코드는 v2 그대로 유지했습니다.

설정
/bxp menu → 라벨 텍스트 선택 → 경험치 + 평판
스톰윈드가 이미 추적 중이면 교체 후 별도 재선택은 필요하지 않습니다.

검증
실제 텍스트 생성기, 숫자 형식, LibDataBroker 객체와 변경 콜백을 연결해
사진과 동일한 경험치 및 평판 값이 한 라벨로 전달되는 것을 확인했습니다.
라벨 관련 9개 및 기존 평판 관련 10개 모의 검사,
Lua 69개 문법 및 TOC/XML 참조 89개 검사를 통과했습니다.
실제 게임 클라이언트에서의 실행은 검증하지 못했습니다.
