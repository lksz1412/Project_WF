PitBull4 Forever v3 — 디버프 표시 경로 수정
대상: WoW Forever 1.60.1 / Interface 16001
날짜: 2026-10-15

설치
1. 게임을 종료합니다.
2. ZIP 안의 PitBull4 폴더를 Interface/AddOns에 덮어씁니다.
3. 게임을 다시 실행합니다.
기존 WTF와 프로필은 그대로 사용합니다. 설정을 초기화하지 않습니다.
이 ZIP에는 PitBull4만 들어 있습니다. Reflux는 기존 것을 사용합니다.

v3 수정
기존 오라 스캔은 보호된 데이터로 분류된 항목을 건너뛰었습니다.
Forever의 기본 CustomAuraContainer를 이용해 디버프를 표시하는 경로를
추가했습니다. 보호된 오라를 애드온이 직접 읽거나 분석하지 않고,
게임의 보안 코드가 아이콘, 중첩, 남은 시간, 추가/해제와 툴팁을 처리합니다.
대상 토큰이 그대로인 대상 전환도 명시적으로 갱신합니다.

위치, 너비, 성장 방향과 반전, 내/다른 사람 디버프의 크기, 문자/타이머
설정과 테두리를 반영합니다. 오라 모듈 또는 디버프 표시를 사용자가
꺼 둔 배치는 자동으로 켜지 않습니다. 설정 미리보기는 기존 방식을 씁니다.

기본 오라 표시 경로의 차이와 범위
- 디버프 필터가 '없음'인 배치에 적용됩니다. 임의의 고급 PitBull 필터는
  보호된 정보를 평가할 수 없어 기존 필터 처리 경로를 유지합니다.
- 기본 API의 표시 개수 제한은 그룹별입니다. 내 디버프와 다른 사람의
  디버프에 각각 '최대 디버프 수'가 적용됩니다. 기존 총합 제한과 다릅니다.
- 남은 시간의 색상은 설정된 고정 색상입니다. 보호된 시간을 Lua로
  비교하는 시간별 색상, 오라 기반 프레임 강조, Masque 스킨은 이 새
  디버프 경로에서 사용하지 않습니다. 기본 테두리와 글꼴을 사용합니다.
- 버프/무기 강화와 다른 모듈의 기존 처리는 변경하지 않았습니다.
- 기본 오라 템플릿이 없는 클라이언트에서는 기존 표시 경로를 사용합니다.

디버프 표시 설정 확인
/pb → 유닛 → 대상 → 배치 이름 확인
/pb → 배치 편집기 → 해당 배치 → 효과(오라)
오라 모듈과 디버프 표시를 켜고, 디버프 필터는 '없음'으로 설정합니다.
플레이어 프레임의 디버프가 필요하면 플레이어가 쓰는 배치도 확인합니다.
제공된 DevilUI 프로필은 플레이어용 '보통' 배치의 오라를 꺼 둡니다.
이번 수정은 그 저장 설정을 강제로 바꾸지 않습니다.

기존 v2 수정 유지
일반/보호된 체력과 부족 체력의 UnitHealthPercent 조회 세 곳에서
예측 체력 사용(true)을 유지합니다. 숫자와 게이지의 기준을 통일한
v2의 HealthBar.lua는 바이트 단위로 그대로 유지했습니다.

검증
Lua 문법과 TOC/XML 로드 경로, 기존 체력/자원/시전/문자/설정 UI/
프로필/프레임 복원 검증을 실행했습니다.
새 디버프 경로는 모의 클라이언트에서 단위 전환, 활성화/해제, 그룹별
크기/시간 표시, 제한 중 스타일 변경의 재시도, 템플릿 부재 시 대체
경로를 점검했습니다. 실제 게임 엔진과 전투 표시는 여기서 검증하지 못했습니다.
ZIP CRC와 전체 압축 해제 및 원본 바이트 일치를 확인했습니다.

저장 변수
PitBull4DB를 그대로 사용하며 정상 종료 또는 /reload 때 게임이 저장합니다.
DogTagTexts는 선택 모듈입니다. 이 묶음은 내장 LuaTexts를 사용합니다.
