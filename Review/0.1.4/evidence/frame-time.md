# 한 접속에서 프레임 시간 비교

같은 캐릭터, 해상도, 화면 배율, 그래픽 설정, 최대 프레임 설정, 장소와 카메라를 사용한다. 화면을 다시 불러온 직후에는 로딩과 초기 갱신이 끝난 뒤 기록한다. [기존 화면 확인표](../../../References/codex-verify/one-session-review.md)

## 측정 도구

[프레임 시간 측정 도구](https://github.com/lksz1412/Project_WF/releases/download/v0.1.4/DevilForever-FrameTimeProbe.zip)는 게임 기본 상태와 Devil Forever 시험판 양쪽에서 같은 파일을 사용한다. 확인하는 날에만 켠다. 별도 명령을 실행한 동안만 프레임 간격을 읽고, 명령 직후 첫 프레임부터 다음 프레임까지의 간격을 첫 표본으로 쓴다. 결과에는 측정 이름과 시간, 프레임 수, 중간값, 95번째·99번째 백분위와 가장 느린 프레임을 기록한다. 95번째 백분위가 20밀리초면 기록한 프레임의 95%가 20밀리초 안에 처리됐다는 뜻이다.

```text
/dfperf start base-idle 30
/dfperf start kit-idle 30
/dfperf report
/dfperf cancel
```

명령의 이름은 같은 자리에서 두 번째 측정인지, 평시인지 전투인지 구분할 수 있게 바꾼다. 완료 결과는 채팅에 표시되며 최근 12개의 요약을 `DevilForever_PerfProbeDB`에 기록한다.

## 비교 순서

| 순서 | 상태 | 같은 입력에서 확인 |
|---|---|---|
| 1 | 게임 기본과 측정 도구 | 같은 장소에서 고정 화면과 반복 가능한 전투를 각각 30초 기록. 다른 애드온이 로드됐는지 대조 |
| 2 | 0.1.4 기본 PitBull4 구성과 같은 측정 도구 | 같은 장면에서 30초 기록. 시전·소환수·퀘스트와 오라가 제때 보이는지 함께 확인 |
| 3 | 차이가 반복되는 경우 | 한 번에 Hekili, Details 또는 유닛 프레임 하나의 조건만 바꿔 다시 측정. 맞는 장면끼리 중간값과 95번째·99번째 백분위를 비교 |
| 4 | FUF 비교가 필요한 경우 | 기본 PitBull4와 번갈아 사용. 같은 대상·오라·시전 요소를 켜고 되풀이한다 |

측정 범위에 로딩, 메뉴 열기나 캐릭터 이동 같은 다른 동작이 섞이면 그 구간을 따로 표시한다. 대상 간 전투나 장면 차이로 설명할 수 있는 성능 차이는 반복 확인한다. 기능별 화면·오류 결과는 기존 확인표에 함께 남긴다.

0.1.4는 새 Quartz 기본 프로필에서만 별도 오라 막대를 끈다. 다른 캐릭터 또는 시전 모듈이 이미 쓰는 공용 프로필도 보존한다. 이미 쓰는 설정이 있으면 별도의 비교 프로필을 복제하고 해당 막대만 끈 상태를 따로 기록한다. 비교 뒤 원래 프로필을 선택한다.
