# 0.1.4 인계 확인

이 브랜치의 설치 목록과 소스를 실제 0.1.4에 맞췄다. 기존 GitHub 목록에 남아 있던 Prat 항목을 제거하고, 실제로 동봉된 자체 채팅 스킨과 나머지 애드온을 세 판에 맞춰 기록했다. [채팅 결정](chat-decision.md) · [설치 목록](../../../Collection/install.json)

## 인계 범위와 연결

| 입력 | 누락 경로 | 새 체크아웃에서 쓰는 곳 |
|---|---|---|
| 이전 모음집의 성능 비교 입력 | 로컬 0.1.1 ZIP | 필요한 원본 멤버 33개를 시험 자료로 보관 |
| FUF·PitBull4·Details 시험 입력 | 무시되는 upstream과 로컬 시험 사본 | FUF·Details는 동봉 소스 사용, PitBull4 원본 TOC 네 개와 Details 배치 세 개는 해시로 확인 |
| 테마 도구와 승인 이미지 | 로컬 렌더러, 추적되지 않던 도안과 출력 | 승인 픽셀 대조 및 Lua의 테마·해상도 적용 시험 |
| 실행 절차와 확인 기록 | 로컬 결과와 압축 파일 경로 | 인계 문서에서 현재 소스, 시험 자료, 공개 원본 ZIP, 실제 게임 확인표로 연결 |

기존 무시 규칙은 계속 적용된다. 회귀 실행기는 현재 동봉 소스의 사본을 새 폴더에 만들고 변형별 시험을 실행한다. 기존 빌드 전용 다섯 건의 제외 이유와 자료 출처는 [회귀 안내](../tests/README.md)에 있다.

## 실행 결과

Git에 등록한 파일만 새 폴더에 꺼내 Windows에서 Python 3.12와 Lua 5.1 시험으로 확인했다. 로컬 작업 폴더와 upstream 폴더를 쓰지 않았다.

| 확인 | 결과 |
|---|---|
| 기준 파일 | 애드온 2,558개와 별도 후보 ZIP 네 개의 해시 일치 |
| 회귀 | 8개 묶음 통과. 수를 세는 195건과 Details 배치, 성능 호출 수 시험 포함 |
| 설치 ZIP | 기본판 2,313개, FUF판 2,249개, 한 접속 비교판 2,558개의 애드온 파일이 공개 원본과 바이트 일치. 필수 의존성 누락과 중복 0건 |
| Quartz와 프레임 측정 도구 | 프로필 36건, Core에서 Quartz까지 15건, 측정 도구 8건 통과 |
| 테마 | 승인 UHD 12종의 픽셀 차이 0, 갤러리 13종 확인. Lua 테마·해상도 조합 39건, 대체 조건 57건, 사용자 수정 45건 통과 |
| 문서 | 현재 인계와 실행에 쓰는 17개 문서의 저장소 안 링크 확인 |

재조립한 ZIP 컨테이너의 해시는 공개 ZIP의 해시와 다를 수 있다. 위의 바이트 일치는 ZIP 안 애드온 파일을 뜻한다. 게임 접속과 실제 화면·프레임 시간 확인은 [한 접속 확인표](../../../References/codex-verify/one-session-review.md)에 남아 있다.
