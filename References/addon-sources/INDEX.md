# 조사한 애드온 원본 ZIP과 개별 분석

기록일: 2026-11-18. 조사에서 확인한 서로 다른 **71종** 전부를 원본 ZIP과 개별 분석으로 연결했다. 기존 Forever 원본 13개는 그대로 재사용하고 추가 원본 58개를 받았다. 취득 실패는 0개다.

원래 요청의 13개는 모두 Forever / 1.60.1 배포 파일이다. 추가 자료는 공식 파일 페이지에 Forever가 표시된 배포를 우선했고, 그 표기를 확인하지 못한 제품은 공식 배포본 또는 commit 소스 ZIP을 코드 참고용으로 보존했다. 파일 표기와 실제 작동은 구분한다. 전체 이력의 최신 판을 전수 조사했다는 뜻은 아니며, 캐시 관측 시점 차이는 SOURCE의 정확한 파일·날짜로 구분한다.
