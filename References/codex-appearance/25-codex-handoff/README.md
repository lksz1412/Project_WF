| 담당 | 적용할 값과 조건 |

## 승인 외관의 낱개 운용

승인 그림을 실제 표시 크기로 펼친 뒤, 위쪽을 왼쪽 연결부·긴 단축바·오른쪽 연결부로 나누고 아래쪽을 세 채팅창·명령부·미니맵으로 나눴다. 13종과 세 해상도의 39개 조합에서 독립 조각을 같은 자리에 그리면 밝은 배경과 어두운 배경 모두 합성판과 보이는 픽셀 차이가 0이다. [조각 대조 결과](piece-comparison.json)

현재 제공되는 낱개 틀의 면과 구분선은 승인 원화의 일부 형태를 담고 있지 않다. 저장할 때 테마별 모서리와 연결부를 함께 잘라야 한다.

| 테마 | 각 조각에 가져갈 그림 |
|---|---|
| 데빌·호드·얼라이언스 | 긴 단축바 양끝과 채팅 상단으로 내려오는 금속 연결부. 데빌 셋째 창도 검회색 단색 면이다. |
| 오크·트롤·포세이큰 | 철판·목각·낮은 아치와 채팅틀로 이어지는 이음새. 줄인 세로 폭과 둥근 모서리를 유지한다. |
| 타우렌·인간·드워프·노움 | 휘는 목재, 성문 측면, 암석 받침, 톱니가 각각 패널 모서리에 붙는 자리. |
| 나이트 엘프 | 단축바 끝과 채팅 모서리를 감싸는 뿌리와 잎. |
| 얼라이언스·호드 스카이본 | 은빛 또는 청동 곡면과 바람결 홈. 두 판에 맞게 얇아진 세로 틀을 유지한다. |

픽셀 대조 경로에서는 오른쪽 채팅 칸에 들어 있는 문양도 같은 조각 안에 있다. 실제로 창 크기를 따로 바꾸려면 채팅 면, 문양, 테두리를 나누고 문양이 바탕 안에서만 그려지게 해야 한다. 원본 왼쪽 70%·상단 70%를 우하단에 쓰고 세로 테두리 앞으로 나오지 않게 한다. 조각을 늘릴 때는 모서리 크기를 유지하고 평평한 가운데 면만 늘린다. 검증은 승인 화면의 고정 크기에서 했으므로 독립 크기 변경과 실제 게임 성능은 별도 시험 대상이다. [13종 승인 외관](../24/racial-appearance/index.md)

## 적응형 배치 제안

현재 Core는 물리 높이 1,400·2,000픽셀을 경계로 첫 프리셋을 고른다. 이 선택을 시작점으로 쓰고 화면 폭과 실제 슬롯 외곽이 맞는지 확인한 뒤 아래부터 쌓는다.

| 물리 값 | FHD | QHD | UHD |
|---|---:|---:|---:|
| Onyx 슬롯 외곽 | 48 | 56 | 80 |
| 슬롯 간격 | 2 | 2 | 2 |
| 중앙 8×3 슬롯의 안쪽 여백 | 6 | 6 | 8 |
| 바닥 여백 | 6 | 6 | 8 |
| 상태띠 높이 | 22 | 24 | 28 |
| 채팅·미니맵 칸 높이 | 192 | 224 | 304 |
| 주 단축바와 채팅 사이 띠 | 10 | 12 | 16 |
| 주 단축바와 위 보조열 사이 | 6 | 6 | 8 |
| 채팅 글자 | 18 | 22 | 28 |

1. 상태띠 아래부터 바닥 여백을 뺀 뒤 상태띠, 채팅과 미니맵, 위쪽의 짧은 띠, 주 단축바, 보조열 순서로 높이를 계산한다.
2. 가운데 슬롯은 여덟 칸씩 세 줄이다. 가운데 패널 폭은 슬롯 여덟 개와 틈 일곱 개에 양쪽 여백을 더한 값이다. 주 단축바는 12칸 묶음 세 개를 놓을 폭이 충분한지 먼저 확인한다. 쓸 수 있는 폭에서 왼쪽·오른쪽 채팅의 읽기 폭을 확보한다.
3. 폭이 부족하면 먼저 12칸 단위로 줄을 재배치하고 선택 부속을 다른 자리로 옮긴다. 모서리의 그림을 글 쪽으로 늘리지 않는다. 슬롯과 글자를 기준 이하로 줄이지 않고, 최소 조건을 못 맞추면 마지막으로 맞았던 배치와 수동 선택을 제공한다.
4. 프레임 위치를 물리 픽셀에서 게임 좌표로 바꾸는 데만 실제 UI 배율을 쓴다. 해상도·배율이 바뀌면 한 번만 다시 계산하고, 전투 중에는 끝날 때까지 적용을 미룬다. 저장한 편집값은 자동 배치보다 우선한다.

## 재현과 입력 한계

저장소 루트에서 현재 Python과 Pillow로 실행한다. 맑은 고딕 글꼴 경로는 Windows 기본 위치다. 출력 경로는 아직 존재하지 않아야 한다. 실행 중 결과를 덮어쓰지 않는다.

```powershell
python -B -I References/codex-appearance/25-codex-handoff/render.py --font "$env:WINDIR/Fonts/malgun.ttf" --output ../phase30-render-fresh
```

[render.py](render.py)는 현재 작업 디렉터리를 저장소 루트로 사용한다. `References/codex-appearance/24/geometry-checks.json`, `feature-positions.json`, `racial-appearance/screens/{fhd,qhd,uhd}-devil.png`, `Collection/AddOns/` 아래 기존 Grid2·PitBull4 TGA와 13종 Composition TGA가 필요하다. 입력이 다른 판이면 같은 결과를 보장하지 않는다. 같은 글꼴·Pillow 버전에서 PNG 3개와 JSON 2개를 재생성하며 좌표·하단 쌓기·조각 대조의 assertion을 실행한다. Python의 최적화 옵션 `-O`는 assertion을 끄므로 사용하지 않는다.

세 그룹을 더한 화면은 데빌 테마 3해상도 예시다. 13종 비교는 각 테마의 기존 top/deck TGA를 고정 표시 크기로 펼친 뒤 영역을 잘라 같은 자리에 재합성하는 대조다. 이 도구는 독립 TGA 파일을 내보내거나 실제 애드온에 적용하지 않는다. `*_deck_reviewed.tga`가 있으면 그것을 쓰고, 없으면 `*_deck.tga`를 쓴다. 실제 읽은 파일과 SHA-256은 [대조 JSON](piece-comparison.json)에 남긴다.

충돌 없음은 JSON에 모델링된 사각형과 새 9개 그룹 사이에서만 확인했다. 네 토템 칸의 숫자·색과 파티 상태는 고정 예시다. 테마별 그림 설명과 적응형 규칙은 구현 제안이며, 폭 부족 시 재배치·UI 배율 환산·전투 뒤 적용·편집값 우선 처리까지 실행한 것은 아니다. 개별 조각 크기 변경, 실제 Grid2/PitBull4 표시 조건, 글자 가독성·시간·주문 아이콘, 게임 성능은 미검증이다.
