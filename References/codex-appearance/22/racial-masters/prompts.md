# 종족 외관 원화 제작 기록

각 외관을 먼저 한 장으로 그렸다. 같은 배치 안내를 사용해 외관 사이의 버튼 위치와 채팅창 크기를 맞췄다. 설치용 이미지는 원화를 프리셋별로 나눠 만든다. 원화 제작 안내에는 게임 문양이 없으며, 오른쪽 채팅창의 문양은 애드온에서 읽는다.
