# Devil Forever 설치기

Windows 11 x64에서 `DevilForeverSetup.exe`를 열면 설치 화면이 나타난다. 실행 파일 옆에 기본 PitBull4 ZIP을 둔다. FUF 단독판은 `ZIP 선택`으로 승인한 파일을 고른다.

1. `폴더 선택`에서 `Wow.exe`가 있는 `_forever_` 폴더를 고른다. `상태 확인`으로 관리 중인 묶음과 미완 실행을 확인한다.
2. 작업과 ZIP을 선택하고 `미리보기`를 누른다. 추가·교체·보존·충돌을 확인한다. 인수가 가능한 기존 폴더는 해당 행의 `인수`를 선택한 뒤 다시 미리보기를 만든다. 원본은 실행별 백업에 보관한다.
3. 실행 가능한 미리보기에서 작업 실행 버튼이 활성화된다. 입력과 선택을 바꾸면 새 미리보기가 필요하다. 처리 중에는 완료를 기다린다.
4. `설치 확인`은 기록과 실제 파일을 읽어 차이를 보여 준다. `결과 복사`는 판·상태·관리 상대 이름과 오류 종류를 복사한다.

`직전 상태 복원`은 미완 작업을 먼저 처리하거나 마지막 완료 적용·제거 이전 상태로 돌아간다. `관리 항목 제거`는 관리 파일과 같은 폴더를 보관 위치로 옮기고 사용자 수정이 있는 폴더를 보존한다. 두 작업 모두 미리보기를 먼저 확인한다. 백업과 실행 기록은 `_forever_/DevilForever-installer`에 있다.

게임에서 해상도와 테마는 기존 `/dfp` 명령으로 고른다. 설치기는 애드온 파일을 관리하며 게임 내 UI의 실제 확인은 한 접속 확인표를 따른다.

명령줄의 `--help`에서 지원하는 명령을 확인할 수 있다. PowerShell에서 Windows 앱을 실행하며 결과를 받으려면 설치기 폴더에서 `Start-Process`로 기다린 뒤 출력과 종료 코드를 읽는다. `--json`을 사용하는 명령도 같은 방식으로 받을 수 있다.

```powershell
$run = Start-Process -FilePath .\DevilForeverSetup.exe -ArgumentList '--help' `
  -Wait -PassThru -RedirectStandardOutput .\installer-help.txt
Get-Content -LiteralPath .\installer-help.txt
$run.ExitCode
```

종료 코드 0은 확인·완료·변경 없음, 2는 입력이나 충돌로 차단, 3은 복구 필요, 4는 설치 기준과의 차이다.
