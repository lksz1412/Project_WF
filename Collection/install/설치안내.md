# 데빌 포에버 모음집 — 처음 설치 안내

WoW Forever 1.60.1 (Interface 16001) 용. 이 안내는 설치 ZIP 안 `DevilForever-install/설치안내.md` 로 함께 간다.

## 이번 로컬 시험판

기본 설치 ZIP은 PitBull4형이다. 공통 외관, 세 해상도 프리셋, 13개 테마와 자체 채팅 외관을 포함한다. 0.1.1에는 채팅창의 얇아진 세로 테두리와 오른쪽 아래 무늬를 넣었다. 기본 채팅 입력과 수신을 사용한다. 0.1.2에는 프리셋과 소환수 단축바에서 반복 화면 갱신을 줄인 자체 Lua를 넣었다.

`DevilForever-0.1.2-one-session.zip`은 두 유닛 프레임을 같은 접속에서 비교할 때만 쓴다. 캐릭터 선택에서 **PitBull4만 켜고** 입장한다. 다른 형을 시험할 때는 PitBull4를 끄고 `ForeverUnitFrames`, `DevilForever_Castbars`, `DevilForever_FUFDefaults`를 켠 상태로 화면을 다시 불러온다. `/dfcheck start`와 `/dfcheck comparison`으로 두 상태를 기록한다.

## 수동으로 격리 시험할 때

아래 순서는 깨끗한 상태에서 비교하기 위해 임시로 애드온을 비워 두는 수동 시험용이다. 설치기를 함께 받았다면 기존 애드온을 둔 채 미리보기에서 충돌과 보존 목록을 확인한다. 이미 깔린 애드온 위에 ZIP을 풀면 같은 폴더에 옛 파일과 새 파일이 섞인다.

1. **백업**: 게임을 완전히 끈다(런처까지). `_forever_/Interface/AddOns` 와 `_forever_/WTF` 를 통째로 다른 곳에 복사해 둔다(예: `forever_backup_install/AddOns`, `.../WTF`). 복사본의 폴더·파일 수가 원래와 같은지 본다.
2. **지금 애드온을 비키기**: `_forever_/Interface/AddOns` 에서 `BugSack`·`!BugGrabber` 를 뺀 **모든** 애드온 폴더를 백업과 다른 폴더 `forever_moved_install/AddOns` 로 옮긴다(지우지 않는다). 이제 `AddOns` 에는 그 둘만 남는다.
3. **풀기**: 설치 ZIP 을 `_forever_` 폴더에 푼다. `Interface/AddOns/` 아래에 모음집 폴더가 들어가고, `_forever_/DevilForever-install/` 에 이 안내와 `manifest.json`(폴더마다 어디서 왔는지·판·고쳤는지), `SHA256SUMS.txt`(파일마다 sha256)가 생긴다.
4. **파일 확인(원하면)**: Windows PowerShell 을 열어 `_forever_` 폴더로 간 뒤 아래 한 줄을 친다. 아무것도 찍히지 않으면 모든 파일이 맞다. 다른 파일은 「다름: <경로>」 로 찍힌다.
   `Get-Content -Encoding UTF8 DevilForever-install/SHA256SUMS.txt | ForEach-Object { $h, $p = $_ -split '  ', 2; if ((Get-FileHash -Algorithm SHA256 -LiteralPath $p).Hash -ne $h.ToUpper()) { "다름: $p" } }`
   Git Bash·Linux 가 있으면 `_forever_` 에서 `sha256sum -c DevilForever-install/SHA256SUMS.txt` 로도 본다.
5. **옛 애드온 되돌리기**: `forever_moved_install/AddOns` 에서 계속 쓸 애드온만 하나씩 `_forever_/Interface/AddOns` 로 옮긴다. 이름이 같은 폴더가 이미 있으면 옮기지 않는다(모음집 판을 쓴다). 아래처럼 모음집과 같은 일을 하는 애드온은 되돌리지 않는다.
   - 시전바: `Dominos_Cast`, V42 `Castbars`, 그 밖의 시전바 애드온 — 시전바는 Quartz 가 맡는다.
   - 경험치·평판·상태 막대: `Dominos_Progress`, `Broker_XPBar`, ChocolateBar·Titan Panel 같은 정보 막대 — 경험치는 Experience Forever, 상태 정보는 `DevilForever_StatusStrip` 이 맡는다.
   - 주사위 창: `Dominos_Roll`, XLoot.
   - unit 프레임: 다른 판의 PitBull4·`PitBull4_DogTagTexts`, Forever Unit Frames(FUF 판을 쓸 때만 넣는다 — 아래).
   - 공격대 프레임: VuhDo 같은 다른 공격대 프레임 — 공격대는 Grid2 가 맡는다.
   - 미터기: ForeverThreat, ThreatClassic2, Skada 같은 미터·위협 애드온 — 데미지와 위협은 Details·Tiny Threat 가 맡는다.
   - 그 밖에 행동단축바(Bartender4 등)·대화창(Prat·Glass·Chattynator 등)·미니맵(BasicMinimap 등)·설정 저장(Reflux 등) 애드온.
6. 폴더 이름 `!DevilForever_Core` 는 `!` 로 시작한다 — 맨 먼저 불러오게 하려는 이름이니 바꾸지 않는다.
7. **자동 업데이트**: CurseForge 앱·WowUp 같은 관리 프로그램을 쓰면 이 ZIP 의 애드온은 모두 「업데이트 무시」(자동 업데이트 끔)로 두는 것이 안전하다. 특히 **PitBull4 는 반드시 끈다** — 켜 두면 Forever 용 고침이 없는 원본으로 덮인다. Hekili·Grid2 처럼 Forever 전용 판이 따로 있는 애드온은 관리 프로그램이 다른 게임판(Retail·Classic) 파일로 바꿀 수 있다(확인 필요) — 업데이트를 켜려면 받는 판이 Forever 판인지 먼저 본다. 판이 바뀌면 모음집 기본값이 맞지 않을 수도 있다.

## 같은 일을 하는 애드온을 함께 켜지 않는다

- unit 프레임은 PitBull4 와 Forever Unit Frames(FUF) 가운데 하나만 켠다. 모음집 기본은 PitBull4 다.
- FUF 전용 설치에는 `DevilForever-0.1.2-fuf.zip`을 쓴다. 기본판과 섞이지 않도록 기존 설치를 아래 절차로 복원한 뒤 다른 ZIP을 적용한다.
- Dominos 묶음의 `Dominos_Cast`·`Dominos_Progress`·`Dominos_Roll` 은 이 ZIP 에 없고 넣지 않는다.

## 캐릭터마다 처음 한 번

- 대화창 3개: 대화창이 아직 기본 상태인 캐릭터로 처음 접속하면 몇 초 뒤 「DevilForever: 대화창 3개를 만들었습니다. /reload 를 입력하면 설정이 마무리됩니다.」 가 뜬다. `/reload` 를 한 번 친다. 자동 배치 기록이 있는 창은 프리셋과 화면 배율을 따라간다. 기존에 따로 나눈 창, 직접 옮기거나 닫은 창, 자동 배치 기록이 없는 이전 설치의 저장 위치는 유지한다.
- 위협 창(Tiny Threat): 대화창에 `/details new` 를 쳐서 Details 창 2 를 열고, 창 2 제목 줄의 모드 단추 → 「플러그인」 → 「Tiny Threat」 를 누른다. 그 뒤로는 Details 가 저장한다.
- 두 창이 준비된 뒤 `/dfdetails apply`를 입력하면 활성 프리셋 위치에 맞춘다. 같은 세션에서 `/dfdetails restore`로 적용 전 위치를 복원할 수 있다. 창 2의 모드와 개인 스킨은 Details에서 설정한다.
- Grid2: 처음 켜질 때 Grid2 가 프로필 고르기 창(「Welcome to Grid2 …」)을 띄운다. 하나를 고른다(검증에서는 「Modern」). 공격대일 때만 Grid2 가 보인다.
- (FUF 를 쓸 때만) Grid2 가 켜진 캐릭터는 접속 20초쯤 뒤 FUF 공격대 프레임이 한 번 꺼진다(공격대는 Grid2 가 맡는다).
- (FUF 배치를 비교할 때만) 접속 뒤 20초가 지나고 전투가 끝나면 `/fuf`의 프로필 메뉴에서 현재 프로필을 복제한다. 이름은 해상도에 맞춰 `DF Compare fhd`, `DF Compare qhd`, `DF Compare uhd` 중 하나를 쓴다. 복제본을 선택하고 `/dffuf layout fhd`, `/dffuf layout qhd`, `/dffuf layout uhd` 중 이름과 맞는 명령을 실행한다. 화면에서 좌표를 확인한 뒤 원래 프로필로 돌아갈 때는 같은 프로필 메뉴에서 원래 이름을 선택한다.
- Cooldown Manager(상태 알림·재사용 대기시간): 게임 설정에서 꺼져 있으면 사람이 직접 켠다(애드온이 바꾸지 않는다).

## 쓰는 명령

- 설정 저장·되돌리기: `/dfp save <이름>` · `/dfp restore <이름>` 뒤 `/dfp go`(UI 를 다시 불러오며 적용). 취소는 `/dfp cancel`. 키 설정·게임 설정은 `/dfp keys …`·`/dfp game …` 을 칠 때만 다룬다. 매크로는 다루지 않는다.
- 테마는 `/dfp theme`으로 이름을 조회하고, 전투 밖에서 `/dfp theme <이름>`으로 바꾼다.
- 실측은 `/dfappearance`와 `/dfcheck start`로 시작한다. `/dfcheck report`로 모인 결과를 본다.
- 상태 띠: `/dfstatus`(칸 켜고 끄기, 시계 12/24 시간). 띠 전체는 애드온 창에서 끈다.
- Experience Forever 설정: `/ef`. Hekili 추천 끄기: `/hekili disable`.

## Aurora 를 쓰기로 정해진 경우에만

Aurora 는 이 ZIP 에 없다(쓸지는 Codex 판정 뒤에 정한다). 넣으면 Aurora 는 접속·`/reload` 때마다 게임 설정 `questTextContrast` 를 4 로 바꾸고, Aurora 를 빼도 4 로 남는다. 원래대로 돌리려면 애드온 없이 `/run SetCVar("questTextContrast", <설치 전 값>)` 을 친다. 설치 전 값을 모르면 `/run SetCVar("questTextContrast", GetCVarDefault("questTextContrast"))` 를 친다. 실제 값은 Codex 결과로 채운다.

## 아직 게임에서 확인되지 않은 것

Lua 실행 대역에서 새 설정 적용, 테마 전환 및 복원, 세 해상도 좌표를 확인했다. 실제 접속에서 화면 배율과 클릭, 채팅 입력, 퀘스트 가독성 및 전투 표시를 확인한다.

## 시험 전 상태로 복원

게임과 런처를 종료한다. 시험에 사용한 `AddOns`와 `WTF`를 각각 다른 이름으로 옮긴다. 설치 직전 백업한 두 폴더를 원래 이름으로 복사한다. 파일 목록과 파일별 SHA256을 백업과 대조한 뒤 게임을 연다.

## 로컬 빌드

정상적인 로컬 원본 폴더가 준비된 저장소에서 `python -I Collection/tools/build.py --install --variant pitbull4 --out-dir <출력경로>`로 기본판을 빌드한다. `fuf`와 `one-session`도 같은 명령으로 선택한다.
