# 코어 원칙 (매체 무관 · 산출물 저작·검수 진입 시 항상 로드)

접근성(색·대비·이중 인코딩)은 `accessibility.md`, 검증 철학은 `verification.md`, 매체 수치·구현은 각 어댑터.

---

## 1. 제1원칙 — 압축 → 시각 배치 (산문 금지)

| 규칙(명사구) |
|---|
| action title = 슬라이드/구획의 **결론을 말하는 완결 문장**(주제 라벨 금지). 제목이 결론, 본문은 증거만 |
| **제목만 읽기 검사** — 제목만 이어 읽어 논증 성립(카탈로그형은 색인 정합으로 대체 → §9) |
| 카드·박스·플로우차트 = 문장 대신 **공간 배치 장치**(제1원칙 정의 자체) |
| 표 셀에 문장이 필요하면 그 항목은 표가 아니라 **카드로 분리** |

## 1-A. 문체 3단 문법 (압축 = 어미 처리, 내용 삭감 아님)

| 층위 | 문체 | 예 |
|---|---|---|
| 제목 | 완결 문장(결론) | "임계 0.35 초과로 폐기" |
| 본문 | 명사구 압축 | "대책 마련"·"~않음" |
| 표 셀 | 키워드(문장 금지) | "초과", "미검출" |
| 정의 | 용어 — 뜻 · 없을 때 문제 | "SOC — 충전율. 미표기 시 오독" |

- 개조식 **명사형 종결** — 조건·수치·괄호는 보존한다.
- **과압축 금지** — 어미를 명사형으로 바꾸는 것이지 caveman 수준 축약(내용 소실)이 아니다.

## 2. 통일성 · 단일 소스 스타일

| 규칙 |
|---|
| **통일성 최우선** — 폰트·박스폭·프레임·여백·색을 문서 전체 단일 규칙으로 고정. "어디는 있고 어디는 없다"가 최다 지적 결함 |
| **layout shift 0** — 매체/화면/시트 전환 시 좌·우·상·하 외곽 여백이 1단위까지 동일 |
| **단일 소스 스타일** — 스타일은 한 곳에서 정의·상속/캐스케이드. 인스턴스에 리터럴 흩뿌리지 않음 |
| 디자인 값(색·크기·여백·그리드) = **토큰**으로 한 곳에 모음 |
| **매체 간 토큰 이식 금지 — 색 포함** — 색·크기·여백은 매체마다 요구가 반대일 수 있음(덱 팔레트 = 발표용 고채도 / 웹 = 구조색 저채도 예산) → 다른 매체의 팔레트를 그대로 가져오지 않고 **그 매체 기준으로 다시 정함**. 같은 브랜드색도 매체가 다르면 hue 만 승계하고 채도·명도 재배정(웹 기준값 = `web_page.md` · 대비는 통과하는데 채도가 과한 반례 = `accessibility.md` §2-2) |

매체별 단일 소스 수단(구현): CSS 변수 상속(`html_css.md`) · pptx 디자인 토큰(PPTX 어댑터) · Qt app QSS + palette 캐스케이드(`pyqt.md`).

## 3. 타이포 위계 — 원리만 (절대 수치는 어댑터)

| 규칙 |
|---|
| 타이포 = **소수의 이산 단계**로 수렴(잡다한 크기 금지) |
| 서체 하나 · 위계는 **크기 + 굵기**로 — 예외 = 코드·식별자 표기용 고정폭 1종 · 에디토리얼 다이어그램의 역할별 서체(`diagram.md` §5) |
| **고정 크기** · autoFit/fit 금지(넘치면 크기 축소 아니라 분할·내용 삭감) |
| 요소 유형별 글자 크기는 **전 페이지 단일**(같은 유형끼리 동일) |

절대 수치(px·pt·°)와 **색값**은 매체마다 다르다 → 각 어댑터가 스케일표·팔레트 소유. **타 매체 절대값·팔레트 무환산 이식 금지**(같은 매체라도 캔버스·DPI 바뀌면 환산 필수 · 색 = §2).

## 4. 근거(exhibit) · 주석

| 규칙 |
|---|
| 시각 단위당 **근거 하나**(표·그림·도식·식). 둘이면 합치거나 나눔 |
| 근거·제목 **상호 필요 검증**(양방향 가림) — 곁들여진 근거는 뺌 |
| 핵심 지점을 **근거 위에 직접 표시**(강조·화살표·음영·주석 중 하나, 한 곳). 주석 = 값 아니라 **판정**("임계 0.35 초과") |
| **발표자 없이 읽히는가** — 배포되어 혼자 읽힘. 요점 안 잡히면 주석 추가 |
| **발표용 원천을 배포용으로 옮길 때**(덱 → 웹 등) — 발표자가 말로 채우던 몫(연결·판정)은 원천 안에서 찾을 수 있는 만큼 주석으로 채움 · 원천에 없는 사실 추가 금지 · 청중 용어 목록(§11)은 새 청중 기준으로 다시 정함 |
| 군더더기 배너·표 밖 자유 텍스트 금지 — 도식이 이미 보여주면 요약 문장 배너 X |

## 5. 다이어그램 의미 정확성 (내용이 곧 UX)

| 규칙 |
|---|
| **분기 vs 순차 구분** — 택1 = 세로순차 아니라 분기. 역할 다른 노드 분리(접으면 분기 소실 오독) |
| **입력→출력·위치·순서를 한 장에** — 위치 축(어디서) 빠지면 구조 안 잡힘. 혼동 지점은 라벨(〔파일〕/〔데이터〕) |
| 다이어그램 = **각진 상자 + 직선 화살표 + 한 방향 흐름** — 각진 = 사각형 계열(모서리 반경은 반경 토큰 허용 · 원·타원·삼각·말풍선 금지) · 흐름 방향은 한 도식 안에서 하나(가로 캔버스 = 좌→우 · 세로로 읽는 웹 페이지 = 위→아래 허용 · 한 도식 안 방향 섞기·곡선 금지) · **매체 예외** = 에디토리얼 다이어그램(`diagram.md` 머리 「코어 §5 명시 예외」 — 커넥터 직교 둥근 elbow · 형태·방향이 곧 뜻인 타입) |
| **좁은 폭 방향 전환(이 규칙이 원본)** — 가로 순차 흐름은 좁은 폭에서 도식 전체를 위→아래로 함께 바꿔도 됨(화살표도 함께 회전 · 도식 일부만 돌리기 금지) · **행 대응(행마다 좌→우 짝)은 좌→우 유지**(돌리면 대응이 순차로 오독) · 웹의 좁은 폭 기준 = `web_page.md` §4 · 컴포넌트 = `html_css.md` §6-2 |
| 묶음 상자 = 상하좌우 동일 여백, 라벨은 상자 **밖(위)** |
| 화살표 라벨 = 화살표 옆 소글씨로 분리(가로 화살표는 위 · 세로 화살표는 오른쪽 · 한 줄 몰기 금지) |

HTML 반복 도식은 손좌표 SVG 대신 상속 컴포넌트 → `html_css.md`(벡터 렌더 자체 금지 아님).

## 6. 레이아웃 · 정렬 · 리듬

| 규칙 |
|---|
| 프레임 폭 = 본문 컬럼 폭, **단일 프레임** — 같은 영역을 테두리 두 겹으로 감싸지 않음(구획 테두리 + 도식 틀 테두리 금지 · 틀 안 노드 테두리는 해당 없음) |
| 박스 폭 = max-width 고정 + **중앙**. 특정 박스만 넓히지 않음(내용은 축약/높이) |
| **수직 리듬 = 균일 간격** — 구역→첫박스 0px 붙임 금지, 분기점에도 화살표 |
| 줄바꿈도 사양 — 우연한 2줄 감김 방치 금지(1줄 압축 또는 잘 나눈 2줄) · 대상 = 제목·박스/카드 제목·표 헤더·라벨 같은 짧은 줄(본문 문단은 흐름대로) · 판정 폭 = 설계 기준 폭(웹 = 1280px) + 좁은 폭 1회(웹 = 640px — 줄머리 기호·한두 글자 꼬리만 결함) · 한글 `word-break:keep-all` + `overflow-wrap:anywhere`(HTML · 병행 사유·표 칸·가운뎃점 예외 = `web_page.md` §3) |

매체 수치(안전 여백·그리드·시트 root·좌패널 폭)는 어댑터.

## 9. ★ 레이아웃 의도 축 — 논증형 vs 카탈로그/시리즈형

**축이 규칙을 반전시킨다.** 매체 무관: HTML 카탈로그 카드·PyQt 시트셋도 시리즈형.

| 축 | 목적 | 제1 시각 규범 |
|---|---|---|
| **논증형** | 결론 하나 밀기 | 내용 유형별 형태 선택 — 같은 레이아웃이 이어져도 된다 |
| **카탈로그·시리즈형** | 구성물 N개 규격 나열 | **균일성** — 동종 규격(헬퍼·필드·기하) 이탈이 결함. 리듬은 부 구획·유형 교대가 만듦 |

### 반전 규칙 (축에 따라 뒤집히는 조항)

| 조항 | 논증형 | 카탈로그·시리즈형 |
|---|---|---|
| 제목 형태 | 결론 문장(action title) | `[N부] 명사 라벨`(색인) — 문장형 제목이 결함 |
| 제목만 읽기 | 논증 성립 검사 | **색인 정합** 검사 |
| 레이아웃 반복 | 내용에 맞으면 허용 | **동일 규격 반복이 규범** |
| 카드 높이 | (해당 없음) | 줄 수 등간격 함수(diet 금지·단일고정 금지) · 칸 간격·내부여백 통일 · 형제 계열 달라도 치수 일치 |
| 표 | (근거 하나) | 동종 2개 병렬 허용(병합 금지) · 헤더 중앙 · 코드값 중앙/서술 좌측 · 볼드 위계 통일 |
| 색 | 주의 유도만 | 연한 틴트 채움 + 브랜드 글자(진채움+흰글자는 표지·구획만) · 역할 박스 색 구분 금지 |

## 10. 제목 형태 (의도 축 · 매체 충돌 해소)

| 맥락 | 형태 |
|---|---|
| 논증 단위 | 결론 문장(action title) |
| 카탈로그·색인 | 명사 라벨 `[N부] …` |
| 구조 라벨(GroupBox·섹션) | 명사 |
| 층위가 여럿인 페이지(발췌 모음 등) | 층위마다 축을 따로 — 목차·구획 머리 = 명사 라벨 · 구획 제목 = 논증이면 결론 문장 · 구획 안 하위 단위 = 하위 결론 |

공통: 제1원칙(압축) · `제목 — 부연` 꼬리 금지(부연은 본문/캡션으로).

## 11. 청중 대응 · 구성물 소개 (콘텐츠 선택도 배치다)

| 규칙 |
|---|
| **청중 대응** — 청중이 이미 아는 용어 목록을 먼저 정하고, 그 밖 용어는 전부 정의 대상. 하향 조정(비유·안심 문구·마케팅 어투) 금지 — 낯선 건 지능 아니라 도메인. 결론만 주지 말고 **선택 기준** 제시 |
| 용어 정의 형식 = §1-A(용어 — 뜻 · 없을 때 문제) |
| **구성물 소개 = 고정 필드 세트** — 동종 구성물은 매번 같은 필드·같은 배치(시리즈 균일 §9). 필드 하나라도 빠지면 미완. 효과 주장엔 근거, 없으면 "근거 미발견"(지어내지 않음) |
