# 참조 — 게이트 개별 사고 실측

`SKILL.md` §8 검증 삼각의 하위 참조. **재사용 규칙은 §8에, 여기엔 1회성 게이트 사고의 실측** — 정규식·파서·스코프가 어떻게 조용히 틀렸는지의 재현 가능한 증거. false-green/false-red는 대부분 이 층에서 태어난다. 근거 태그: `A L##`=transcript 대장 · `C L##`=committed 대장 — **두 대장은 개발 저장소에만 있고 배포본에 포함되지 않는다**(태그는 개발 이력 추적용 표시일 뿐 읽는 쪽이 열어볼 대상이 아니다).

## 정규식·파서가 조용히 틀린 곳

- **문자클래스 대문자 누락**: 옛 `[a-z0-9_]`는 대문자 `BH_LKS_`를 못 잡음 → `[A-Za-z0-9_]`(A L97).
- **포인터 파서 strict `$` 앵커 오탐**: 결합행(`· skill:`)·마침표·괄호주석 4줄을 dangling으로 오탐 → `[ \t]*(?:$|[·.);])` 로 완화(부정 픽스처는 여전히 거부해야, A L114).
- **placeholder 오탐**: 문서용 `BH:BH_LKS_X`·`<전체 이름>`을 dangling으로 오탐 → placeholder-tolerant 정규식(A L117).
- **`grep -E` 리터럴 파이프 오매치**: `\|`가 대안(alternation)으로 해석돼 덱 카운트가 통째로 틀림(A L118).
- **버전 패턴 부분문자열 오탐**: `ver.a`가 `leftover.append` 안에서 매치 → 단어경계(A L119).
- **검색패턴 형태 누락**: `profile-b`만 검색해 "Profile A는" prose 12건을 놓침 → 토큰의 모든 표기를 sweep(A L115).

## 스코프가 비어서 통과한 곳

- **리네임 sweep 확장자 범위 누락**: `.md`만 훑어 `sync.sh`·README의 bare `LKS_`가 생존(A L116).
- **교차게이트 스코프 완결**: 루트 CLAUDE.md `@import`가 재계수 스코프 밖이라 dangling이 세 게이트 green 생존 → "토큰 잃어야 할 파일은 그걸 잡는 **모든** sweep 스코프에"(A L103).
- **Phase별 재계수 스코프 분리**: P2-end는 memory만·P3-end는 전 패턴, deck/PG는 소유 Phase(A L105).
- **descope placeholder 폴더 잔존**: 삭제된 Codex 참조를 담은 `.gitkeep`이 full-surface sweep서야 적발(A L120).

## 라벨·역사가 게이트를 오염시킨 곳

- **version-sweep 라벨 충돌**: `1.1.5-rev`은 버전이 아니라 **모델정책 개정 라벨** → `grep 1.1.5`로 0 만들면 훼손. 스윕을 배너로 한정 + 정책 라벨·역사 주석 면제(A L106).
- **역사 문건 면제 명문화**: CHANGELOG는 리네임 면제임을 계획에 박아야(안 하면 과잉치환·재적발, A L151).
- **negtest lockstep 새 축**: 버전 헤딩(헌법 헤딩 ↔ negtest 라인이 byte 결합) → 동반 1커밋(A L107).

## 훅 라이브 작동 사고 (인과 tier 주의)
